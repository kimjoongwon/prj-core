# proposal-page-data 기획서

> 수정일: 2026-03-28

> 위치: apps/proposal/web/src/app/proposal-page-data.ts

## 역할

`/proposal` 랜딩 페이지가 사용하는 정적 제안 데이터와 하단 경력/이력서 보강 섹션의 타입 계약을 소유합니다.

## 공개 계약

| 항목 | 설명 |
|------|------|
| `proposalPageData` | Hero, 문제 정의, 접근 방식, 비용 구조, 기술 스택, 하단 경력·이력·포트폴리오 섹션까지 포함한 정적 데이터 |
| 타입 export | `SectionId`, `ProposalPageData`, `ProposalCareerEntry`, `ProposalResumeFact`, `ProposalPortfolioItem` 등 페이지 렌더링 타입 계약 |

## 의존성

없음. 정적 데이터와 타입만 정의합니다.

## 동작 흐름

1. 페이지가 import 시점에 정적 제안 데이터와 경력, 이력서 상세, 포트폴리오 데이터를 읽습니다.
2. `page.tsx`는 상단 랜딩 섹션과 하단 builder background 섹션을 동일한 데이터 모듈에서 렌더링합니다.

## 실패 및 엣지 케이스

- 브라우저 API나 네트워크 의존성이 없습니다.
- 데이터 구조가 바뀌면 `page.tsx`의 타입 검사로 즉시 드러납니다.
- 상단 내비게이션은 `career` 섹션을 직접 노출하지 않으므로, `SectionId`에 `career`가 존재해도 탐색 버튼과는 분리됩니다.

## 구현 체크리스트

- [x] 정적 데이터는 직렬화 가능한 값만 사용함
- [x] 페이지가 소비하는 타입 계약과 함께 export 함
- [x] 하단 경력 섹션은 실전 프로젝트 경력과 함께 이력서 요약, 자격, 포트폴리오를 포함함
