# proposal-page-data 기획서

> 생성일: 2026-03-21
> 타입: data
> 위치: apps/proposal/web/src/app/proposal-page-data.ts

## 역할

`/proposal` 랜딩 페이지가 사용하는 정적 소개 데이터와 타입 계약을 소유합니다.

## 공개 계약

| 항목 | 설명 |
|------|------|
| `proposalPageData` | 랜딩 섹션별 직렬화 가능한 정적 데이터 |
| 타입 export | `SectionId`, `ProposalPageData` 등 페이지 렌더링 타입 계약 |

## 의존성

없음. 정적 데이터와 타입만 정의합니다.

## 동작 흐름

1. 페이지가 import 시점에 정적 소개 데이터를 읽습니다.
2. `page.tsx`는 이 데이터를 그대로 랜딩 섹션 렌더링에 사용합니다.

## 실패 및 엣지 케이스

- 브라우저 API나 네트워크 의존성이 없습니다.
- 데이터 구조가 바뀌면 `page.tsx`의 타입 검사로 즉시 드러납니다.

## 구현 체크리스트
