# 03. 인터랙션 정의

## 사용자 액션

| 액션 | 트리거 | 결과 |
|------|--------|------|
| 탭 변경 | 탭 클릭 | URL 변경 + 해당 상태 회원 필터링 |
| 검색 | 검색어 입력 + 엔터/버튼 | 이름/이메일/전화번호로 검색 |
| 행 선택 | 체크박스 클릭 | 선택 상태 토글 + 일괄 작업 바 표시 |
| 전체 선택 | 헤더 체크박스 클릭 | 현재 페이지 전체 선택/해제 |
| 회원 등록 | "+ 회원 등록" 버튼 클릭 | 회원 등록 페이지로 이동 |
| 상세 보기 | 행 클릭 (체크박스 외) | 회원 상세 페이지로 이동 |
| 수정 | 액션 메뉴 > 수정 | 회원 수정 페이지로 이동 |
| 삭제 | 액션 메뉴 > 삭제 | 삭제 확인 모달 표시 |
| 일괄 상태 변경 | 일괄 작업 바 > 상태 변경 | 상태 선택 모달 표시 |
| 일괄 삭제 | 일괄 작업 바 > 삭제 | 삭제 확인 모달 표시 |
| 페이지 이동 | 페이지 번호 클릭 | 해당 페이지 데이터 로드 |

---

## 상태 변화 흐름

```
페이지 진입
    ↓
데이터 로딩 중 표시 (스켈레톤)
    ↓
데이터 로드 완료
    ├─ 데이터 있음 → 목록 표시
    └─ 데이터 없음 → 빈 상태 표시
    ↓
사용자 인터랙션
    ├─ 탭 변경 → URL 변경 → 필터링된 데이터 로드
    ├─ 검색 → 검색어로 필터링
    ├─ 행 선택 → 일괄 작업 바 표시/숨김
    ├─ 등록 → 등록 페이지 이동
    ├─ 상세 → 상세 페이지 이동
    ├─ 수정 → 수정 페이지 이동
    └─ 삭제 → 확인 모달 → 삭제 처리 → 목록 갱신
```

## 모달 정의

### 삭제 확인 모달

```
┌──────────────────────────────────┐
│         회원 삭제                 │
├──────────────────────────────────┤
│                                  │
│  선택한 회원을 삭제하시겠습니까?  │
│  (삭제된 회원은 복구할 수 없습니다)│
│                                  │
├──────────────────────────────────┤
│    [취소]           [삭제]       │
└──────────────────────────────────┘
```

**버튼 스타일:**
- 취소: `variant="flat"`
- 삭제: `color="danger"`

---

### 상태 변경 모달

```
┌──────────────────────────────────┐
│         상태 변경                 │
├──────────────────────────────────┤
│                                  │
│  선택한 3명의 상태를 변경합니다.  │
│                                  │
│  변경할 상태:                     │
│  ○ 활성                          │
│  ○ 휴면                          │
│  ○ 탈퇴대기                       │
│                                  │
├──────────────────────────────────┤
│    [취소]           [변경]       │
└──────────────────────────────────┘
```

**버튼 스타일:**
- 취소: `variant="flat"`
- 변경: `color="primary"`
