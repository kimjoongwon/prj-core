# 04. UI 상세

## 반응형 대응

### 브레이크포인트

| 크기 | 범위 | 대응 방식 |
|------|------|----------|
| Desktop | >=1280px | 전체 테이블 UI, 사이드바 표시 |
| Tablet | 768-1279px | 테이블 유지, 일부 컬럼 숨김, 햄버거 메뉴 |
| Mobile | <768px | 테이블 → 카드 뷰 전환, 바텀탭 |

### 모바일 대체 UI

| 데스크톱 UI | 모바일 대체 |
|------------|------------|
| 테이블 | 카드 뷰 |
| 일괄 작업 버튼 | 플로팅 액션 바 |
| 행 액션 메뉴 | 더보기(...) 버튼 |

---

## 테이블 컬럼

| 컬럼명 | 필수 | Desktop | Tablet | Mobile | 비고 |
|--------|:----:|:-------:|:------:|:------:|------|
| 선택 (체크박스) | ✅ | - | - | - | 항상 표시 |
| 이름 | ✅ | - | - | - | 항상 표시 |
| 이메일 | ❌ | ✅ | ❌ | ❌ | Desktop만 표시 |
| 전화번호 | ✅ | - | - | - | 항상 표시 |
| 등급 | ✅ | - | - | - | 항상 표시 |
| 가입일 | ❌ | ✅ | ❌ | ❌ | Desktop만 표시 |
| 상태 | ✅ | - | - | - | 항상 표시 |
| 액션 (더보기) | ✅ | - | - | - | 항상 표시 |

> `-` = 필수 컬럼 (항상 표시)
> `✅` = 해당 디바이스에서 기본 표시
> `❌` = 해당 디바이스에서 기본 숨김

## 상태별 UI

### 로딩 상태

- 테이블/카드 영역에 스켈레톤 UI 표시
- 탭 바와 검색창은 즉시 표시

### 빈 상태

```
┌─────────────────────────────────┐
│                                 │
│         👤 (아이콘)              │
│                                 │
│    등록된 회원이 없습니다.       │
│    새로운 회원을 등록해 주세요.  │
│                                 │
│       [+ 회원 등록]              │
│                                 │
└─────────────────────────────────┘
```

### 검색 결과 없음

```
┌─────────────────────────────────┐
│                                 │
│         🔍 (아이콘)              │
│                                 │
│  "홍길동"에 대한 검색 결과가     │
│  없습니다.                       │
│                                 │
│  다른 검색어로 시도해 보세요.    │
│                                 │
└─────────────────────────────────┘
```

### 에러 상태

```
┌─────────────────────────────────┐
│                                 │
│         ⚠️ (아이콘)              │
│                                 │
│    데이터를 불러오지 못했습니다.  │
│    잠시 후 다시 시도해 주세요.   │
│                                 │
│         [다시 시도]              │
│                                 │
└─────────────────────────────────┘
```

## 회원 상태 표시

| 상태 | 색상 | Chip 표시 |
|------|------|----------|
| 활성 (ACTIVE) | success (초록) | 🟢 활성 |
| 휴면 (DORMANT) | warning (노랑) | 🟡 휴면 |
| 탈퇴대기 (PENDING_WITHDRAWAL) | danger (빨강) | 🔴 탈퇴대기 |

---

## 버튼 상태

| 버튼 | 조건 | 상태 |
|------|------|------|
| 회원 등록 | - | 항상 enabled |
| 일괄 상태 변경 | 선택된 항목 없음 | disabled |
| 일괄 삭제 | 선택된 항목 없음 | disabled |
| 삭제 확인 | - | `color="danger"` |
