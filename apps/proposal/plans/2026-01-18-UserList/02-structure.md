# 02. 화면 구조

## Desktop 레이아웃 (>=1280px)

```
┌─────────────────────────────────────────────────────────────────────┐
│ [SideNav]  │              회원 목록                                  │
│            │─────────────────────────────────────────────────────────│
│            │  ┌─────────────────────────────────────────────────┐   │
│            │  │ [전체] [활성] [휴면] [탈퇴대기]          (탭 바) │   │
│            │  └─────────────────────────────────────────────────┘   │
│            │                                                         │
│            │  ┌─────────────────────────────────────────────────┐   │
│            │  │ 🔍 [           검색어 입력            ]  [검색]  │   │
│            │  │                                     [+ 회원 등록] │   │
│            │  └─────────────────────────────────────────────────┘   │
│            │                                                         │
│            │  ┌─────────────────────────────────────────────────┐   │
│            │  │ □ │ 이름   │ 이메일        │ 전화번호   │ 등급  │   │
│            │  │   │        │               │            │       │   │
│            │  │   │ 가입일 │ 상태          │      액션          │   │
│            │  │───┼────────┼───────────────┼────────────┼───────│   │
│            │  │ □ │ 홍길동 │ hong@mail.com │ 010-1234-  │ VIP   │   │
│            │  │   │        │               │ 5678       │       │   │
│            │  │   │ 24.01.15│ 🟢 활성      │  [···]             │   │
│            │  └─────────────────────────────────────────────────┘   │
│            │                                                         │
│            │  ┌─────────────────────────────────────────────────┐   │
│            │  │         < 1 2 3 4 5 ... 10 >        (페이지네이션)│   │
│            │  └─────────────────────────────────────────────────┘   │
│            │                                                         │
│            │  [선택 항목: 3개]        [일괄 상태 변경] [일괄 삭제]   │
│            │  (선택 시에만 표시되는 일괄 작업 바)                     │
└─────────────────────────────────────────────────────────────────────┘
```

## Mobile 레이아웃 (<768px)

### 기본 상태

```
┌─────────────────────────────────┐
│ ☰  회원 목록              [+]   │
├─────────────────────────────────┤
│ [전체][활성][휴면][탈퇴대기]    │
├─────────────────────────────────┤
│ 🔍 [     검색어 입력      ] 🔍  │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ □  홍길동            VIP   │ │
│ │    010-1234-5678    🟢활성 │ │
│ │                       [···]│ │
│ └─────────────────────────────┘ │
│ ┌─────────────────────────────┐ │
│ │ □  김철수            일반  │ │
│ │    010-9876-5432    🟡휴면 │ │
│ │                       [···]│ │
│ └─────────────────────────────┘ │
├─────────────────────────────────┤
│         < 1 2 3 ... >           │
├─────────────────────────────────┤
│ [BottomTab]                     │
└─────────────────────────────────┘
```

> 테이블 → 카드 뷰 전환

### 선택 모드

```
┌─────────────────────────────────┐
│ [취소]  3개 선택               │
├─────────────────────────────────┤
│         (카드 목록)             │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │  [상태 변경]    [삭제]      │ │  ← 플로팅 액션 바
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

---

## 컴포넌트 구성

| 영역 | 컴포넌트 | 설명 |
|------|----------|------|
| Header | 페이지 제목 | "회원 목록" 텍스트 + 등록 버튼 |
| Tab Bar | 상태 탭 | 전체/활성/휴면/탈퇴대기 |
| Toolbar | 검색 + 액션 | 검색창, 회원 등록 버튼 |
| Content | 테이블/카드 | 회원 목록 표시 |
| Footer | 페이지네이션 | 페이지 이동 |
| Floating | 일괄 작업 바 | 선택 시 나타나는 액션 바 |
