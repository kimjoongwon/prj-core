# 01. 화면 개요

## 목적

시설(Ground)에 등록된 회원 정보를 관리하기 위한 화면입니다.

- 회원 상태를 한눈에 파악
- 회원 정보 조회/등록/수정/삭제
- 상태별 필터링으로 빠른 관리

---

## 진입 조건

| 조건 | 설명 |
|------|------|
| Admin 로그인 | 관리자 인증 완료 |
| Ground 선택 | 시설(Ground) 선택 완료 |
| 권한 | `menu:users:list` 권한 보유 |

---

## 이탈 조건

| 이벤트 | 이동 경로 |
|--------|----------|
| 다른 메뉴 클릭 | 해당 메뉴 페이지 |
| 행 클릭 | 회원 상세 페이지 (`/users/[id]`) |
| 등록 버튼 클릭 | 회원 등록 페이지 (`/users/new`) |
| 수정 클릭 | 회원 수정 페이지 (`/users/[id]/edit`) |

---

## 데이터 필드

### 목록 표시 데이터

| 필드 | 한글명 | 타입 | 설명 |
|------|--------|------|------|
| id | ID | string | 회원 고유 식별자 |
| name | 이름 | string | 회원 이름 |
| email | 이메일 | string | 이메일 주소 |
| phone | 전화번호 | string | 연락처 |
| grade | 등급 | string | 회원 등급 (VIP, 일반 등) |
| status | 상태 | enum | ACTIVE, DORMANT, PENDING_WITHDRAWAL |
| createdAt | 가입일 | datetime | 가입 일시 |

### 검색 대상 필드

- 이름 (name)
- 이메일 (email)
- 전화번호 (phone)

> 통합 검색으로 위 3개 필드를 동시에 검색
