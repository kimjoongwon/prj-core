# 06. 레이아웃 구조

## 1. Desktop

```
┌─────────────────────────────────────────────────────────────────┐
│ [🔍 검색] [역할▼] [가입일 📅]              [내보내기▼] [+ 등록]  │ <- Header
├─────────────────────────────────────────────────────────────────┤
│ □ │ 이름   │ 이메일        │ 전화번호    │ 역할  │ 상태 │ 액션  │
├───┼────────┼───────────────┼─────────────┼───────┼──────┼───────┤
│ □ │ 홍길동  │ hong@...     │ 010-...    │ USER │ 활성 │ ⋮    │
│ □ │ 김철수  │ kim@...      │ 010-...    │ ADMIN│ 활성 │ ⋮    │
├─────────────────────────────────────────────────────────────────┤
│ 총 100건                                      [< 1 2 3 ... >]  │ <- Footer (Pagination)
└─────────────────────────────────────────────────────────────────┘
```

## 3. 레이아웃 구성 요소

### Header (상단 영역)

| 영역 | 요소 | 설명 |
|------|------|------|
| leftInputs | 검색, 필터 | nuqs 자동 연동 |
| rightInputs | 버튼, 드롭다운 | 액션 수행 |

### Body (테이블 영역)

| 상태 | 컴포넌트 | 설명 |
|------|----------|------|
| 로딩 | TablePageSkeleton | 스켈레톤 UI |
| 빈 상태 | TablePageEmpty | 빈 상태 메시지 |
| 데이터 | DataGrid | TanStack Table |

### Footer (하단 영역)

| 영역 | 요소 | 설명 |
|------|------|------|
| 좌측 | 총 건수 | 전체 데이터 수 |
| 우측 | Pagination | nuqs 연동 페이지네이션 |

### ActionBar (선택 시)

| 요소 | 설명 |
|------|------|
| 선택 건수 | "N건 선택됨" |
| 액션 버튼 | 일괄 삭제, 상태 변경 등 |
