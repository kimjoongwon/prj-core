## v7.0 핵심 변경: 항상 펼침 사이드바

### 기존 (v6.0 이전)

```
📊 대시보드
▶ 👥 사용자      <- 클릭하면 펼침/접힘 토글
▶ 📅 예약
▶ ⚙️ 설정
```

- Accordion 방식으로 한 번에 하나의 메뉴만 펼침
- 사용자가 다른 메뉴 위치를 파악하기 어려움

### 변경 (v7.0)

```
📊 대시보드

👥 회원
   회원 목록      <- 모든 2depth가 항상 표시
   등급 관리
   탈퇴 회원

📅 예약
   오늘 예약
   예약 목록
   캘린더
   통계
```

- 모든 2depth 메뉴가 항상 표시됨
- 전체 메뉴 구조를 한눈에 파악 가능
- 원하는 메뉴로 바로 이동 (토글 클릭 불필요)

## Header

### 구성 요소

| 영역 | 내용 |
|------|------|
| 좌측 | 로고 |
| 우측 | 알림 배지 + Space 셀렉터 + 유저 아바타 메뉴 |

### 스타일

- 높이: 64px
- 배경: 반투명 + 블러 효과
- 테두리: 하단 구분선

### 인터랙션

| 액션 | 결과 |
|------|------|
| 로고 클릭 | 대시보드로 이동 |
| 알림 배지 클릭 | 알림 목록 페이지로 이동 |
| Space 셀렉터 클릭 | Space 선택 페이지로 이동 |
| 아바타 클릭 | 로그아웃 메뉴 표시 |

## Sidebar

### 스타일

- 너비: 240px (고정)
- 배경: bg-content1
- 테두리: 우측 구분선
- 스크롤: 콘텐츠 영역만 스크롤 (Header 고정)

### 1depth 메뉴 스타일

| 상태 | 스타일 |
|------|--------|
| 기본 | text-default-500, 아이콘 포함 |
| 호버 | bg-default-100 |
| 활성 (하위 선택됨) | text-primary, font-semibold |

### 2depth 메뉴 스타일

| 상태 | 스타일 |
|------|--------|
| 들여쓰기 | padding-left: 40px |
| 기본 | text-default-400, text-sm |
| 호버 | bg-default-100 |
| 활성 | bg-primary/10, text-primary, font-medium |

### 메뉴 그룹 간격

1depth 메뉴 간에는 여백을 두어 시각적 그룹핑:

```

                    <- gap-2 (8px)

   회원 목록
   등급 관리
   탈퇴 회원
                    <- gap-2 (8px)
📅 예약
   오늘 예약
   ...
```

## 인터랙션

### 항상 펼침 모드에서의 동작

| 액션 | 결과 |
|------|------|
| 대시보드 클릭 | 대시보드 페이지로 이동 |
| 1depth 메뉴 클릭 | 첫 번째 2depth 페이지로 이동 |
| 2depth 메뉴 클릭 | 해당 페이지로 이동 |

### 활성 상태 표시

- 현재 페이지의 2depth 메뉴: 활성 스타일 적용
- 해당 1depth 메뉴: 활성 스타일 적용 (하위가 선택됨을 표시)

## 3depth 상단 탭 (pathParam 방식)

페이지 내 상단에 탭으로 표시되는 하위 분류. **각 탭은 별도 경로**를 가집니다.

```
+----------------------------------------------------+
|  [전체] [활성] [휴면] [탈퇴대기]                    |  <- 3depth 탭
+----------------------------------------------------+
|                                                     |
|              페이지 콘텐츠                          |
|                                                     |
+----------------------------------------------------+
```

### 경로 매핑

| 탭 | 경로 |
|----|------|
| 전체 | /users |
| 활성 | /users/active |
| 휴면 | /users/dormant |
| 탈퇴대기 | /users/pending-withdrawal |

### 스타일

- 위치: 페이지 콘텐츠 영역 상단
- 컴포넌트: HeroUI Tabs
- 활성 탭: primary underline
- 비활성 탭: text-default-500
- 탭 클릭: Next.js Link로 경로 이동

### 예시

| 2depth 페이지 | 3depth 탭 (경로) |
|--------------|------------------|
| 회원 목록 | /users, /users/active, /users/dormant, /users/pending-withdrawal |
| 예약 목록 | /reservations, /reservations/pending, /reservations/confirmed, /reservations/cancelled |
| 문의 목록 | /inquiries, /inquiries/pending, /inquiries/completed |

### 구현 패턴

```typescript
// layout.tsx에서 탭 UI 렌더링
const tabs = [
  { id: 'all', label: '전체', href: '/users' },
  { id: 'active', label: '활성', href: '/users/active' },
  { id: 'dormant', label: '휴면', href: '/users/dormant' },
  { id: 'pending-withdrawal', label: '탈퇴대기', href: '/users/pending-withdrawal' },
];

// 현재 경로로 활성 탭 판단
const pathname = usePathname();
const activeTab = tabs.find(tab => pathname === tab.href)?.id || 'all';
```
