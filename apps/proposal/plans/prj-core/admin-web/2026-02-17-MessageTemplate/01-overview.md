# L0-L2: 컨텍스트, 사용자, 목표

## L0: 시스템 컨텍스트

### 도메인 정의

| 항목 | 내용 |
|------|------|
| **도메인명** | MessageTemplate (메시지 템플릿 관리) |
| **범위** | Email/SMS/Push 메시지 템플릿 CRUD + 변수 관리 + 미리보기 + 발송 테스트 |
| **설명** | 시스템 관리자가 다양한 채널(Email, SMS, Push)의 메시지 템플릿을 등록/관리하고, 변수 치환 미리보기 및 테스트 발송을 수행할 수 있는 기능 |

### 핵심 비즈니스 개념

- **메시지 템플릿(MessageTemplate)**: 특정 채널로 발송되는 메시지의 원형. 고유 코드(code)를 가지며 백엔드에서 코드로 조회하여 실제 발송에 사용
- **템플릿 유형(TemplateType)**: 메시지 채널 유형 (Email, SMS, Push). 유형에 따라 사용 가능한 필드와 제약이 다름
- **템플릿 변수(TemplateVariable)**: 템플릿 본문에 삽입되는 플레이스홀더 (예: `{{userName}}`, `{{orderNo}}`). 발송 시 실제 데이터로 치환됨
- **미리보기(Preview)**: 변수를 샘플 데이터로 치환하여 실제 렌더링 결과를 확인하는 기능
- **발송 테스트(SendTest)**: 작성한 템플릿을 특정 수신자에게 실제로 발송하여 결과를 검증하는 기능
- **템플릿 코드(Code)**: 시스템 내에서 고유한 식별 코드. 백엔드 서비스에서 코드 기반으로 템플릿을 조회하여 메시지 발송에 활용

### 시스템 경계

```
┌─────────────────────────────────────────────────────────────┐
│                    Admin Web Application                     │
├─────────────────────────────────────────────────────────────┤
│  [메시지 템플릿 관리 화면]                                    │
│   - 템플릿 목록 (유형별 필터, 검색, 활성/비활성 필터)         │
│   - 템플릿 상세 (내용 + 변수 목록)                           │
│   - 템플릿 등록/수정 (유형 선택, 내용 작성, 변수 정의)        │

│   - 템플릿 활성/비활성 토글                                   │
```

## L1: 사용자 (Actor)

### 사용자 정의

| ID | 사용자 | 역할 | 주요 행동 |
|----|--------|------|----------|
| MT-L1-ACT-001 | 시스템 관리자 | FULL_ACCESS | 모든 템플릿 CRUD, 미리보기, 발송 테스트, 변수 관리 |
| MT-L1-ACT-002 | Space 관리자 | MANAGE | 자신의 Space 범위 내 템플릿 조회/사용 (향후 확장) |

### 사용자 특성

#### 시스템 관리자 (FULL_ACCESS)

- **목표**: 시스템에서 사용하는 모든 메시지 템플릿을 등록/관리하고, 발송 전 미리보기 및 테스트를 통해 품질을 보장
- **기술 수준**: 메시지 템플릿 변수 문법(`{{변수명}}`) 이해, 채널별 메시지 특성 이해 (HTML 이메일, 문자 길이 제한, 푸시 제목/본문 등)
- **접근 권한**: System Space (ROOT Category) 전용, CASL: `can('manage', 'messageTemplate')`

#### Space 관리자 (MANAGE)

- **목표**: 자신의 Space에서 사용 가능한 템플릿을 조회하고, 필요시 템플릿 코드를 확인하여 발송 로직에 활용
- **기술 수준**: 기본적인 템플릿 구조 이해
- **접근 권한**: 해당 Space 범위 내, CASL: `can('read', 'messageTemplate')`
- **참고**: 1차 구현에서는 시스템 관리자 위주로 개발하며, Space 관리자 기능은 향후 확장 예정

## L2: 사용자 목표 (Goal)

### 목표 정의

| ID | 목표 | 사용자 | 우선순위 | 설명 |
|----|------|--------|----------|------|
| MT-L2-GOL-001 | 템플릿 목록 조회 | 시스템 관리자 | 높음 | 유형별 필터/검색으로 등록된 템플릿 현황 파악 |
| MT-L2-GOL-002 | 템플릿 상세 확인 | 시스템 관리자 | 높음 | 특정 템플릿의 내용과 변수 목록 확인 |
| MT-L2-GOL-003 | 템플릿 등록 | 시스템 관리자 | 높음 | 새 메시지 템플릿 생성 (유형 선택, 내용 작성, 변수 정의) |
| MT-L2-GOL-004 | 템플릿 수정 | 시스템 관리자 | 높음 | 기존 템플릿의 내용/변수/설정 변경 |
| MT-L2-GOL-005 | 템플릿 삭제 | 시스템 관리자 | 중간 | 불필요한 템플릿 제거 |
| MT-L2-GOL-006 | 템플릿 활성/비활성 토글 | 시스템 관리자 | 높음 | 템플릿의 사용 여부를 활성/비활성으로 전환 |
| MT-L2-GOL-007 | 템플릿 미리보기 | 시스템 관리자 | 높음 | 변수를 샘플 데이터로 치환하여 실제 렌더링 결과 확인 |
| MT-L2-GOL-008 | 발송 테스트 | 시스템 관리자 | 중간 | 특정 수신자에게 테스트 메시지를 실제 발송하여 검증 |
| MT-L2-GOL-009 | 변수 관리 | 시스템 관리자 | 높음 | 템플릿에서 사용하는 변수(placeholder) 추가/수정/삭제 |

### 목표 상세

#### MT-L2-GOL-001: 템플릿 목록 조회

**동기**: 시스템에 등록된 메시지 템플릿 현황을 한눈에 파악하고, 유형별로 분류하여 관리

**성공 기준**:
- 전체 템플릿 목록 표시 (코드, 이름, 유형, 활성 상태, 생성일)
- 유형별 필터링 (Email / SMS / Push / 전체)
- 활성/비활성 상태별 필터링
- 이름/코드로 검색 가능
- 페이지네이션 지원

#### MT-L2-GOL-002: 템플릿 상세 확인

**동기**: 특정 템플릿의 전체 내용, 설정, 사용 중인 변수를 상세히 확인

**성공 기준**:
- 템플릿 기본 정보 표시 (코드, 이름, 유형, 설명, 활성 상태)
- 유형별 콘텐츠 표시 (Email: 제목+HTML 본문, SMS: 본문, Push: 제목+본문)
- 정의된 변수 목록과 각 변수의 설명/기본값 표시
- 생성일/수정일 타임스탬프 표시

#### MT-L2-GOL-003: 템플릿 등록

**동기**: 새로운 메시지 발송 시나리오에 맞는 템플릿을 생성하여 시스템에 등록

**성공 기준**:
- 유형 선택 (Email / SMS / Push)
- 고유 코드(code) 입력 (중복 검증)
- 유형별 필수 필드 입력 (Email: 제목+본문, SMS: 본문, Push: 제목+본문)
- Email 유형의 경우 HTML 편집 지원
- 변수 정의 (변수명, 설명, 기본값)
- 등록 후 상세 화면으로 이동

#### MT-L2-GOL-004: 템플릿 수정

**동기**: 기존 템플릿의 내용, 변수, 설정을 업데이트

**성공 기준**:
- 기존 데이터가 폼에 미리 채워짐
- 코드(code)는 수정 불가 (읽기 전용)
- 유형(type)은 수정 불가 (읽기 전용)
- 내용/변수/설명 등 수정 가능
- 수정 후 상세 화면으로 이동

#### MT-L2-GOL-005: 템플릿 삭제

**동기**: 더 이상 사용하지 않는 템플릿을 시스템에서 제거

**성공 기준**:
- 삭제 전 확인 다이얼로그 표시
- 삭제 시 관련 변수 데이터도 함께 제거 (Soft Delete)
- 삭제 후 목록 화면으로 이동 및 목록 갱신

#### MT-L2-GOL-006: 템플릿 활성/비활성 토글

**동기**: 템플릿을 삭제하지 않고 일시적으로 사용 중지하거나, 다시 활성화

**성공 기준**:
- 목록 또는 상세 화면에서 토글 가능
- 비활성화된 템플릿은 발송 시 사용 불가 (백엔드 검증)
- 상태 변경 즉시 UI 반영

#### MT-L2-GOL-007: 템플릿 미리보기

**동기**: 발송 전 변수가 치환된 최종 렌더링 결과를 확인하여 오류 방지

**성공 기준**:
- 정의된 변수에 샘플 데이터 입력 가능
- 변수 치환 후 렌더링 결과 실시간 표시
- Email: HTML 렌더링 결과 미리보기
- SMS: 문자 길이 계산 및 표시
- Push: 제목+본문 미리보기
- 미리보기 결과에서 미치환 변수(`{{...}}`) 잔존 시 경고 표시

#### MT-L2-GOL-008: 발송 테스트

**동기**: 실제 발송 환경에서 템플릿이 정상적으로 전달되는지 검증

**성공 기준**:
- 수신자 정보 입력 (Email: 이메일 주소, SMS: 전화번호, Push: 디바이스 토큰 또는 사용자 선택)
- 변수 값 입력 (샘플 데이터)
- 테스트 발송 실행 및 결과(성공/실패) 표시
- 발송 실패 시 오류 메시지 표시

#### MT-L2-GOL-009: 변수 관리

**동기**: 템플릿에서 사용하는 변수를 체계적으로 관리하여 일관성 유지

**성공 기준**:
- 변수 추가 (변수명, 한글 설명, 기본값, 필수 여부)
- 변수 수정 (설명, 기본값 등)
- 변수 삭제 (본문에서 사용 중인 변수 삭제 시 경고)
- 변수명은 영문 카멜케이스 규칙 준수 (예: `userName`, `orderNo`)
- 템플릿 본문과 변수 목록 간 정합성 검증
