# L3-L4: 기능, 화면

## 이전 레이어 요약 (L0-L2)

- **L0 Context**: 관리자가 시스템 내 이용자 목록을 조회하고 검색/필터링하는 기능
- **L1 Actor**: 관리자 (ADMIN) - 이용자 조회 권한 보유
- **L2 Goals**: 목록 조회, 검색, 필터링, 정렬

---

### 기능 목록

| ID | 기능명 | 목표 연결 | 우선순위 | 설명 |
|----|--------|----------|----------|------|

### 기능 상세

#### USR-L3-FEA-001: 이용자 목록 표시

**설명**: DataGrid를 사용하여 이용자 목록을 테이블 형태로 표시

**표시 컬럼**:
| 컬럼 | 필드 | 너비 | 정렬 |
|------|------|------|------|
| 번호 | seq | 80px | 지원 |
| 이름 | name | 150px | 지원 |
| 이메일 | email | 200px | 지원 |
| 전화번호 | phone | 150px | - |
| 역할 | tenants[0].role.name | 120px | - |
| 상태 | 계산됨 (removedAt 기반) | 100px | - |
| 가입일 | createdAt | 120px | 지원 |

**페이지네이션**:
- 페이지당 20건 (기본값)
- 페이지 크기 변경: 10, 20, 50, 100

#### USR-L3-FEA-002: 통합 검색

**설명**: 단일 검색창에서 이름, 이메일, 전화번호를 동시에 검색

**동작**:
- 검색어 입력 후 Enter 또는 검색 버튼 클릭
- Debounce 적용 (300ms)
- 검색 결과 0건 시 "검색 결과가 없습니다" 메시지

#### USR-L3-FEA-003: 필터 패널

**설명**: 다양한 조건으로 이용자 목록 필터링

**필터 항목**:
| 필터 | 타입 | 복수 선택 | 기본값 |
|------|------|----------|--------|
| 역할 | Checkbox Group | O | 전체 |
| 상태 | Radio Group | X | 전체 |
| 분류 | Select | X | 전체 |
| 그룹 | Multi-Select | O | 전체 |
| 가입일 시작 | DatePicker | - | 없음 |
| 가입일 종료 | DatePicker | - | 없음 |

**동작**:
- 필터 변경 시 즉시 목록 갱신
- 필터 초기화 버튼 제공

#### USR-L3-FEA-004: 정렬 기능

**설명**: 컬럼 헤더 클릭으로 정렬

**정렬 가능 필드**:
- 번호 (seq)
- 이름 (name)
- 이메일 (email)
- 가입일 (createdAt)

**동작**:
- 첫 클릭: 오름차순
- 재클릭: 내림차순
- 삼클릭: 정렬 해제

#### USR-L3-FEA-005: 통계 표시

**설명**: 페이지 상단에 이용자 통계 카드 표시

**표시 항목**:
- 전체 이용자 수
- 활성 이용자 수
- 비활성 이용자 수

**UI 상태**:

| 상태 | 조건 | 표시 |
|------|------|------|
| 로딩 | API 호출 중 | DataGrid 스켈레톤 |
| 빈 상태 | 결과 0건 | "조회된 이용자가 없습니다" |
| 에러 | API 실패 | 에러 메시지 + 재시도 버튼 |
| 정상 | 데이터 있음 | 목록 표시 |

**권한 체크**:
- CASL: `can('read', 'user')`
- 권한 없음 시 접근 불가 페이지 표시
