## 디자인 목업

> 페이지의 전체 UI 레이아웃을 ASCII로 표현합니다.

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   [ 브라우저 주소창: http://example.com/ ]           │
│                                                     │
│   ┌─────────────────────────────────────────────┐   │
│   │                                             │   │
│   │   (UI 없음 - 서버 사이드 리다이렉트)         │   │
│   │                                             │   │
│   │   → /auth/login 으로 즉시 이동              │   │
│   │                                             │   │
│   └─────────────────────────────────────────────┘   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 사용자 시나리오

1. 사용자가 앱의 루트 경로(`/`)에 접근한다
2. 인증 쿠키가 있으면 대시보드(`/dashboard`)로 이동한다
3. 인증 쿠키가 없으면 로그인 페이지(`/auth/login`)로 리다이렉트된다
