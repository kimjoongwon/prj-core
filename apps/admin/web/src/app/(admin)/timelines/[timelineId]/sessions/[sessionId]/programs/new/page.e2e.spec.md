# 프로그램 등록 E2E 기획서

> 생성일: 2026-03-16
> 타입: e2e
> 위치: apps/admin/web/src/app/(admin)/timelines/[timelineId]/sessions/[sessionId]/programs/new/page.e2e.ts

## 역할

프로그램 등록 후 수정 화면에서 루틴 전환이 정상 동작하는지, 그리고 테스트가 전용 태스크를 사용해 다른 E2E 시나리오와 데이터 충돌 없이 수행되는지 검증합니다. 준비/정리 API 요청은 브라우저 컨텍스트의 인증/Space 쿠키를 그대로 재사용하며, 세션 상세의 프로그램 버튼 클릭 후 URL 전환과 핵심 CTA를 기준으로 상세 진입 완료를 판단합니다.

## 시나리오

| ID | 설명 |
|----|------|
| E2E-001 | 타임라인, 세션, 전용 태스크, 루틴 2개, 강사를 준비한 뒤 프로그램을 등록할 수 있어야 함 |
| E2E-002 | 등록한 프로그램을 수정 화면에서 다른 루틴으로 전환하고 저장할 수 있어야 함 |
| E2E-003 | 테스트 종료 시 프로그램, 세션, 타임라인, 루틴, 전용 태스크를 정리해 다른 시나리오에 영향을 남기지 않아야 함 |
