## 사용자 시나리오

1. 관리자가 AI 폼 템플릿 목록 페이지에 접근하여 전체 템플릿 현황을 파악한다
2. 필터(도메인, 제공자, 상태)를 사용하여 원하는 템플릿을 검색한다
3. 검색어를 입력하여 특정 템플릿명으로 검색한다
4. 템플릿 행을 클릭하여 상세 페이지로 이동한다
5. "템플릿 등록" 버튼을 클릭하여 새 템플릿을 등록한다
6. 템플릿 현황 및 실행 통계를 확인하여 AI 활용 현황을 모니터링한다

## DataGrid 컬럼

| 컬럼 | 필드 | 설명 | Cell 컴포넌트 |
|------|------|------|---------------|
| 템플릿명 | name | 템플릿 이름 + 설명 | TextCell |
| 도메인 | targetDomain | 대상 도메인 | BadgeCell |
| 제공자 | aiProvider | AI 제공자 아이콘 + 텍스트 | AIProviderCell |
| 모델 | model | 사용 모델명 | TextCell |
| 필드수 | fieldCount | 설정된 필드 수 | NumberCell |
| 상태 | isActive | 활성/비활성/초안 배지 | StatusCell |
| 등록일 | createdAt | 날짜 | DateCell |
