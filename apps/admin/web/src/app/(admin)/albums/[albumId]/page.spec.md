## L3: 기능 (Feature)

### 목적

앨범에 포함된 에셋을 관리합니다. 에셋 추가/제거, 순서 변경, 캡션 편집 등을 지원합니다.

### 주요 기능

| ID | 기능 | 설명 |
|----|------|------|
| F-001 | 앨범 에셋 목록 조회 | 앨범에 포함된 에셋을 그리드로 표시 |
| F-002 | 에셋 추가 | 에셋 선택기를 통해 앨범에 에셋 추가 |
| F-003 | 에셋 제거 | 앨범에서 에셋 제거 (AlbumEntry 삭제) |
| F-004 | 순서 변경 | 드래그앤드롭으로 에셋 순서 변경 |
| F-005 | 캡션 편집 | 각 에셋의 캡션 편집 |
| F-006 | 앨범 정보 수정 | 앨범명, 설명, 커버 이미지 변경 |
| F-007 | 앨범 삭제 | 앨범 삭제 (AlbumEntry도 함께 삭제) |

### 접근 권한

| Actor | 접근 가능 여부 | 비고 |
|-------|---------------|------|
| ACT-001 (FULL_ACCESS) | 가능 | 전체 Space 앨범 조회/관리 |
| ACT-002 (MANAGE) | 가능 | 현재 Space 앨범 조회/관리 |
| ACT-003 (VIEW) | 가능 | 조회만 가능 (추가/제거/수정 불가) |

## 사용자 시나리오

1. **앨범 상세 진입**: 앨범 목록에서 카드 클릭 시 상세 페이지 진입
2. **에셋 목록 확인**: 앨범에 포함된 에셋 그리드로 확인
3. **에셋 추가**: "에셋 추가" 버튼 → 에셋 선택기 → 선택 완료 → 앨범에 추가
4. **에셋 제거**: 카드의 x 버튼 → 확인 → 앨범에서 제거
5. **순서 변경**: "순서 편집" 모드 → 드래그앤드롭 → 저장
6. **캡션 편집**: 카드 더블클릭 또는 캡션 클릭 → 모달 → 캡션 입력 → 저장
7. **앨범 정보 수정**: "수정" 버튼 → 모달 → 정보 변경 → 저장
8. **앨범 삭제**: "삭제" 버튼 → 확인 → 삭제

## API 호출

| 시점 | API | 캐싱 |
|------|-----|------|
| 진입 | `GET /api/v1/albums/{albumId}` | React Query staleTime 30s |
| 진입 | `GET /api/v1/albums/{albumId}/entries` | 30s |
| 에셋 추가 | `POST /api/v1/albums/{albumId}/entries` | 캐시 무효화 |
| 에셋 제거 | `DELETE /api/v1/albums/{albumId}/entries/{entryId}` | 캐시 무효화 |
| 순서 변경 | `PATCH /api/v1/albums/{albumId}/entries/reorder` | 캐시 무효화 |
| 캡션 편집 | `PATCH /api/v1/albums/{albumId}/entries/{entryId}` | 캐시 무효화 |
| 앨범 수정 | `PATCH /api/v1/albums/{albumId}` | 캐시 무효화 |
| 앨범 삭제 | `DELETE /api/v1/albums/{albumId}` | 캐시 무효화 |
