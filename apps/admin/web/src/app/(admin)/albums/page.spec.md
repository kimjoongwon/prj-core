## L3: 기능 (Feature)

### 목적

사용자 정의 에셋 컬렉션인 앨범을 관리합니다. 앨범은 폴더와 분리된 독립적인 분류 체계입니다.

### 주요 기능

| ID | 기능 | 설명 |
|----|------|------|
| F-001 | 앨범 목록 조회 | 앨범 카드 형태로 목록 표시 |
| F-002 | 앨범 생성 | 새 앨범 생성 (이름, 설명, 커버 이미지) |
| F-003 | 앨범 수정 | 이름, 설명, 커버 이미지 변경 |
| F-004 | 앨범 삭제 | 소프트 삭제 |
| F-005 | 앨범 검색 | 앨범 이름 검색 |
| F-006 | 커버 이미지 설정 | 에셋 선택기를 통해 커버 이미지 선택 |

### 접근 권한

| Actor | 접근 가능 여부 | 비고 |
|-------|---------------|------|
| ACT-001 (FULL_ACCESS) | 가능 | 전체 Space 앨범 조회/관리 |
| ACT-002 (MANAGE) | 가능 | 현재 Space 앨범 조회/관리 |
| ACT-003 (VIEW) | 가능 | 조회만 가능 (생성/수정/삭제 불가) |

## 사용자 시나리오

1. **앨범 목록 조회**: 앨범 카드 형태로 목록 확인
2. **앨범 생성**: "앨범 생성" 버튼으로 모달 오픈 → 정보 입력 → 저장
3. **앨범 상세 진입**: 카드 클릭 시 상세 페이지로 이동
4. **앨범 수정**: 카드의 수정 버튼으로 모달 오픈 → 정보 수정 → 저장
5. **앨범 삭제**: 카드의 삭제 버튼 → 확인 다이얼로그 → 삭제
6. **앨범 검색**: 검색어 입력으로 앨범 필터링
7. **커버 이미지 선택**: 에셋 선택기를 통해 커버 이미지 선택

## API 호출

| 시점 | API | 캐싱 |
|------|-----|------|
| 진입 | `GET /api/v1/albums` | React Query staleTime 30s |
| 검색 | `GET /api/v1/albums?search={keyword}` | 30s |
| 생성 | `POST /api/v1/albums` | 캐시 무효화 |
| 수정 | `PATCH /api/v1/albums/{albumId}` | 캐시 무효화 |
| 삭제 | `DELETE /api/v1/albums/{albumId}` | 캐시 무효화 |
