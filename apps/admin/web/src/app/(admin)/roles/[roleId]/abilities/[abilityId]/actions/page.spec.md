# Action 관리 페이지 기획서

> 생성일: 2026-02-18
> 타입: page
> 경로: `/roles/[roleId]/abilities/[abilityId]/actions`

## 디자인 목업

> 페이지의 전체 UI 레이아웃을 ASCII로 표현합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  [페이지 헤더 영역]                                              │
│                                                             │
│  Action 관리                    [ <- 역할 상세로 ]          │
│  권한의 액션(Action)을 관리합니다.                           │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  [섹션 영역]                                     │  │
│  │                                                       │  │
│  │  권한 ID                                              │  │
│  │  ┌─────────────────────────────────────────────────┐  │  │
│  │  │  `abilityId: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxx`  │  │  │
│  │  └─────────────────────────────────────────────────┘  │  │
│  │                                                       │  │
│  │  ⚠ Action 관리 기능은 추후 구현 예정입니다.            │  │
│  │                                                       │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 사용자 시나리오

1. 관리자가 특정 역할의 특정 권한(Ability)에 대한 액션(Action)을 관리하기 위해 페이지에 진입한다.
2. 현재는 플레이스홀더 상태로, "Action 관리 기능은 추후 구현 예정입니다." 안내가 표시된다.
3. 권한 ID가 코드 형태로 표시된다.
4. "역할 상세로" 버튼으로 역할 상세 페이지로 돌아갈 수 있다.

## 레이아웃 구성

| 영역 | 컴포넌트 | 설명 |
|------|----------|------|

| 콘텐츠 | `Section + SectionHeader` | 권한 ID 표시 + 미구현 안내 |
