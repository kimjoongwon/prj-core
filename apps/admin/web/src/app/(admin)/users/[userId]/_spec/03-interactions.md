# 03-interactions: 이용자 상세

## 이전 레이어 요약 (L3-L4)

- **L3 Features**: 5개 기능 (목록 표시, 통합 검색, 필터 패널, 정렬, 통계)
- **L4 Screens**: 이용자 목록(`/users`), 이용자 상세(`/users/[userId]`), 이용자 등록(`/users/new`), 이용자 수정(`/users/[userId]/edit`)

---

## L5: 인터랙션 정의

### USR-L4-SCR-002: 이용자 상세 화면 (`/users/[userId]`)

#### 사용자 액션

| ID | 액션 | 트리거 | 결과 | 조건 |
|----|------|--------|------|------|
| USR-L5-ACT-010 | 페이지 진입 | URL 접근 | GET /api/v1/users/:id 호출 → 상세 정보 표시 | - |
| USR-L5-ACT-011 | 수정 버튼 클릭 | 페이지 헤더 영역 actions 영역 버튼 클릭 | 수정 화면으로 이동 (`/users/[userId]/edit`) | `can('update', 'user')` |
| USR-L5-ACT-012 | 삭제 버튼 클릭 | 페이지 헤더 영역 actions 영역 버튼 클릭 | 삭제 확인 모달 표시 | `can('delete', 'user')` |
| USR-L5-ACT-013 | 삭제 확인 | 모달에서 삭제 버튼 클릭 | DELETE /api/v1/users/:id 호출 | - |
| USR-L5-ACT-014 | 삭제 취소 | 모달에서 취소 버튼 클릭 | 모달 닫기 | - |
| USR-L5-ACT-015 | 목록으로 이동 | 뒤로가기 또는 목록 링크 클릭 | 이용자 목록 화면으로 이동 (`/users`) | - |

#### 시스템 반응

| 액션 | 성공 시 | 실패 시 |
|------|---------|---------|
| 페이지 진입 | GET /api/v1/users/:id 호출 → 상세 정보 표시 (Profile, Tenant, Role, Space 포함) | 에러 메시지 (404: "사용자를 찾을 수 없습니다") |
| 삭제 확인 | DELETE 호출 → "이용자가 삭제되었습니다" 토스트 → 이용자 목록으로 이동 | 에러 토스트 (400: "자신의 계정은 삭제할 수 없습니다") |

#### 상태 전이

```
[페이지 진입]
    |
    v
[로딩 상태] -- GET /api/v1/users/:id (SSR Prefetch)
    |
    +-- 성공 --> [데이터 표시]
    |                |
    |                +-- 수정 버튼 --> [수정 화면 이동]
    |                +-- 삭제 버튼 --> [삭제 확인 모달]
    |                |                    |
    |                |                    +-- 확인 --> [삭제 처리] --> 성공 --> [목록 이동]
    |                |                    +-- 취소 --> [데이터 표시]
    |                |
    |                +-- 목록으로 --> [목록 화면 이동]
    |
    +-- 실패 --> [에러 상태] --> 재시도 또는 목록 이동
```

```

+------------------------------------+

+------------------------------------+
|    [취소]           [삭제]          |
+------------------------------------+
```

| 요소 | 설명 |
|------|------|
| 제목 | "삭제 확인" |
| 본문 | "정말로 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다." |
| 추가 경고 | 자기 자신인 경우: "자신의 계정은 삭제할 수 없습니다." (삭제 버튼 비활성화) |
| 취소 버튼 | 모달 닫기 (variant="flat") |
| 삭제 버튼 | DELETE API 호출 (color="danger") |

## L6: API 엔드포인트 정의

### USR-L6-API-002: 이용자 상세 조회

| 항목 | 내용 |
|------|------|
| **ID** | USR-L6-API-002 |
| **Method** | GET |
| **Endpoint** | `/api/v1/users/:id` |
| **Operation ID** | `getUserById` |
| **설명** | 특정 사용자의 상세 정보를 조회합니다. Profile, Tenant, Role, Space 정보를 포함합니다. |
| **인증** | Bearer Token |
| **Headers** | `X-Space-ID` (필수) |
| **Path Params** | `id` (UUID) - 사용자 ID |
| **Response** | `UserDetailResponseDto` |
| **에러** | 401 (미인증/Space 미선택), 404 (사용자 없음), 500 |

---

### USR-L6-API-005: 이용자 삭제

| 항목 | 내용 |
|------|------|
| **ID** | USR-L6-API-005 |
| **Method** | DELETE |
| **Endpoint** | `/api/v1/users/:id` |
| **Operation ID** | `deleteUser` |
| **설명** | 사용자를 소프트 삭제합니다. 자신의 계정은 삭제할 수 없습니다. |
| **인증** | Bearer Token |
| **Headers** | `X-Space-ID` (필수) |
| **Path Params** | `id` (UUID) - 사용자 ID |
| **Status Code** | 204 No Content |
| **에러** | 400 (자기 계정 삭제 시도), 401, 404, 500 |
