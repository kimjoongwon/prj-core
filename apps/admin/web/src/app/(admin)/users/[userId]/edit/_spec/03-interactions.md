# 03-interactions: 이용자 수정

## 이전 레이어 요약 (L3-L4)

- **L3 Features**: 5개 기능 (목록 표시, 통합 검색, 필터 패널, 정렬, 통계)
- **L4 Screens**: 이용자 목록(`/users`), 이용자 상세(`/users/[userId]`), 이용자 등록(`/users/new`), 이용자 수정(`/users/[userId]/edit`)

---

## L5: 인터랙션 정의

### USR-L4-SCR-004: 이용자 수정 화면 (`/users/[userId]/edit`)

#### 사용자 액션

| ID | 액션 | 트리거 | 결과 | 조건 |
|----|------|--------|------|------|
| USR-L5-ACT-025 | name 수정 | 이름 Input 변경 | 실시간 유효성 검사 (2~50자) | - |
| USR-L5-ACT-026 | email 수정 | 이메일 Input 변경 | 실시간 유효성 검사 (이메일 형식) | - |
| USR-L5-ACT-027 | phone 수정 | 전화번호 Input 변경 | 실시간 유효성 검사 (한국 휴대폰 형식) | - |
| USR-L5-ACT-028 | categoryId 변경 | 분류 Select 변경 | 선택값 업데이트 | - |
| USR-L5-ACT-029 | groupIds 변경 | 그룹 Multi-Select 변경 | 선택값 업데이트 | - |
| USR-L5-ACT-030 | 저장 버튼 클릭 | 저장 버튼 클릭 | 유효성 검사 후 PATCH /api/v1/users/:id 호출 | 변경된 필드만 전송 |
| USR-L5-ACT-031 | 취소 버튼 클릭 | 취소 버튼 클릭 | 이용자 상세 화면으로 이동 | - |

#### 시스템 반응

| 액션 | 성공 시 | 실패 시 |
|------|---------|---------|
| 페이지 진입 | GET /api/v1/users/:id → 기존 데이터 prefill | 에러 메시지 (404: "사용자를 찾을 수 없습니다") |
| 저장 버튼 클릭 | PATCH 호출 → "이용자 정보가 수정되었습니다" 토스트 → 이용자 상세 화면 이동 | 에러 토스트 (400: 이메일/전화번호/이름 중복) |

#### 유효성 검사

| 필드 | 규칙 | 에러 메시지 |
|------|------|------------|
| name | 선택, 2~50자 | "이름은 2자 이상 50자 이내로 입력해주세요" |
| email | 선택, 이메일 형식 | "올바른 이메일 형식을 입력해주세요" |
| phone | 선택, 한국 휴대폰 형식 (`010-XXXX-XXXX`) | "올바른 전화번호 형식을 입력해주세요" |
| categoryId | 선택 | - |
| groupIds | 선택 | - |

#### 제약사항

- 비밀번호 변경은 수정 화면에서 불가 (별도 기능)
- 역할(roleId) 변경은 수정 화면에서 불가 (별도 관리 기능)
- 변경된 필드만 PATCH 요청에 포함

#### 상태 전이

```

    |                |                    |                    |
    |                |                    |                    +-- 통과 --> [저장 처리 중] (로딩)
    |                |                    |                    |                |
    |                |                    |                    |                +-- 성공 --> [상세 화면 이동]
    |                |                    |                    |                +-- 실패 --> [에러 표시] --> [수정 중]
    |                |                    |                    |
    |                |                    |                    +-- 실패 --> [유효성 에러 표시]
```

## L6: API 엔드포인트 정의

### USR-L6-API-002: 이용자 상세 조회 (기존 데이터 로드용)

| 항목 | 내용 |
|------|------|
| **ID** | USR-L6-API-002 |
| **Method** | GET |
| **Endpoint** | `/api/v1/users/:id` |
| **Operation ID** | `getUserById` |
| **설명** | 수정 폼 prefill을 위해 기존 사용자 정보를 조회합니다. |
| **인증** | Bearer Token |
| **Headers** | `X-Space-ID` (필수) |
| **Path Params** | `id` (UUID) - 사용자 ID |
| **Response** | `UserDetailResponseDto` |
| **에러** | 401, 404, 500 |

---

### USR-L6-API-004: 이용자 수정

| 항목 | 내용 |
|------|------|
| **ID** | USR-L6-API-004 |
| **Method** | PATCH |
| **Endpoint** | `/api/v1/users/:id` |
| **Operation ID** | `updateUser` |
| **설명** | 사용자 정보를 수정합니다. 변경하려는 필드만 전송하면 됩니다. |
| **인증** | Bearer Token |
| **Headers** | `X-Space-ID` (필수) |
| **Path Params** | `id` (UUID) - 사용자 ID |
| **Response** | `UserDto` |
| **에러** | 400 (이메일/전화번호/이름 중복), 401, 404, 500 |

**Request Body** (`UpdateUserMemberDto`):

```json
{
  "name": "수정된 이름",
  "email": "updated@example.com",
  "phone": "010-9876-5432",
  "categoryId": "uuid",
  "groupIds": ["uuid-1"]
}
```

### Orval 생성 훅

```typescript
import {
  useGetUserById,
  useUpdateUser,
  useGetRoleCategories,
  useGetRoleGroups,
  prefetchGetUserById,
} from "@cocrepo/api";

// 기존 데이터 로드
const { data } = useGetUserById(userId);

// 분류/그룹 옵션 조회
const { data: categories } = useGetRoleCategories();
const { data: groups } = useGetRoleGroups();

// 수정
const { mutateAsync: updateUser } = useUpdateUser();
await updateUser({
  id: userId,
  data: {
    name: "수정된 이름",
    email: "updated@example.com",
  },
});
```
