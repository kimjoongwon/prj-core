# 03-interactions: 이용자 등록

## 이전 레이어 요약 (L3-L4)

- **L3 Features**: 5개 기능 (목록 표시, 통합 검색, 필터 패널, 정렬, 통계)
- **L4 Screens**: 이용자 목록(`/users`), 이용자 상세(`/users/[userId]`), 이용자 등록(`/users/new`), 이용자 수정(`/users/[userId]/edit`)

---

## L5: 인터랙션 정의

### USR-L4-SCR-003: 이용자 등록 화면 (`/users/new`)

#### 사용자 액션

| ID | 액션 | 트리거 | 결과 | 조건 |
|----|------|--------|------|------|
| USR-L5-ACT-016 | name 입력 | 이름 Input 입력 | 실시간 유효성 검사 (2~50자) | - |
| USR-L5-ACT-017 | email 입력 | 이메일 Input 입력 | 실시간 유효성 검사 (이메일 형식) | - |
| USR-L5-ACT-018 | phone 입력 | 전화번호 Input 입력 | 실시간 유효성 검사 (한국 휴대폰 형식) | - |
| USR-L5-ACT-019 | password 입력 | 비밀번호 Input 입력 | 실시간 유효성 검사 (8자 이상, 영문+숫자+특수문자) | - |
| USR-L5-ACT-020 | roleId 선택 | 역할 Select 변경 | 선택값 업데이트 | - |
| USR-L5-ACT-021 | categoryId 선택 | 분류 Select 변경 | 선택값 업데이트 | - |
| USR-L5-ACT-022 | groupIds 선택 | 그룹 Multi-Select 변경 | 선택값 업데이트 | - |
| USR-L5-ACT-023 | 등록 버튼 클릭 | 등록 버튼 클릭 | 유효성 검사 후 POST /api/v1/users 호출 | name, email, phone, password, roleId 필수 |
| USR-L5-ACT-024 | 취소 버튼 클릭 | 취소 버튼 클릭 | 이용자 목록으로 이동 | - |

#### 시스템 반응

| 액션 | 성공 시 | 실패 시 |
|------|---------|---------|
| 등록 버튼 클릭 | POST 호출 → "이용자가 등록되었습니다" 토스트 → 이용자 상세 화면 이동 | 에러 토스트 (400: 이메일/전화번호/이름 중복) |

#### 유효성 검사

| 필드 | 규칙 | 에러 메시지 |
|------|------|------------|
| name | 필수, 2~50자 | "이름은 2자 이상 50자 이내로 입력해주세요" |
| email | 필수, 이메일 형식 | "올바른 이메일 형식을 입력해주세요" |
| phone | 필수, 한국 휴대폰 형식 (`010-XXXX-XXXX`) | "올바른 전화번호 형식을 입력해주세요" |
| password | 필수, 8자 이상, 영문+숫자+특수문자 포함 | "비밀번호는 8자 이상, 영문/숫자/특수문자를 포함해야 합니다" |
| roleId | 필수 | "역할을 선택해주세요" |
| categoryId | 선택 | - |
| groupIds | 선택 | - |

## L6: API 엔드포인트 정의

### USR-L6-API-003: 이용자 등록

| 항목 | 내용 |
|------|------|
| **ID** | USR-L6-API-003 |
| **Method** | POST |
| **Endpoint** | `/api/v1/users` |
| **Operation ID** | `createUser` |
| **설명** | 새로운 사용자를 등록합니다. 이메일, 전화번호, 이름은 중복될 수 없습니다. |
| **인증** | Bearer Token |
| **Headers** | `X-Space-ID` (필수) |
| **Status Code** | 201 Created |
| **Response** | `UserDto` |
| **에러** | 400 (이메일/전화번호/이름 중복), 401, 500 |

**Request Body** (`CreateUserMemberDto`):

```json
{
  "name": "홍길동",
  "email": "hong@example.com",
  "phone": "010-1234-5678",
  "password": "Password1!",
  "roleId": "uuid",
  "categoryId": "uuid",
  "groupIds": ["uuid-1", "uuid-2"]
}
```

### Orval 생성 훅

```typescript
import {
  useCreateUser,
  useGetRoles,
  useGetRoleCategories,
  useGetRoleGroups,
} from "@cocrepo/api";

// 역할/분류/그룹 옵션 조회
const { data: roles } = useGetRoles();
const { data: categories } = useGetRoleCategories();
const { data: groups } = useGetRoleGroups();

// 등록
const { mutateAsync: createUser } = useCreateUser();
await createUser({
  data: {
    name: "홍길동",
    email: "hong@example.com",
    phone: "010-1234-5678",
    password: "Password1!",
    roleId: "uuid",
  },
});
```
