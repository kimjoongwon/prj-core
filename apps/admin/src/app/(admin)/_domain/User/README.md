# User (이용자 목록 조회)

> 프로젝트: prj-core / 앱: admin-web

## 개요

관리자가 시스템에 등록된 이용자 목록을 조회할 수 있는 기능입니다.
조회 전용 기능으로, 등록/수정/삭제는 이 기능에 포함되지 않습니다.

## 핵심 기능

- 이용자 목록 조회 (페이징 지원)
- 통합 검색 (이름, 이메일, 전화번호)
- 필터링 (역할, 상태, 분류, 그룹)
- 정렬 (가입일, 이름, 이메일)

## 제약사항

- 조회 전용 (Read-Only)
- 현재 Space 내 이용자만 조회 가능

## 기존 백엔드 연계

이미 구현된 API 사용:
- `GET /api/users` - 이용자 목록 조회
- `GET /api/users/:id` - 이용자 상세 조회 (필요 시)
