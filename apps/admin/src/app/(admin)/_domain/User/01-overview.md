# L0-L2: 컨텍스트, 사용자, 목표

## L0: 시스템 컨텍스트

### 도메인 정의

| 항목 | 내용 |
|------|------|
| **도메인명** | User (이용자 관리) |
| **범위** | 조회 전용 (Read-Only) |
| **설명** | 관리자가 시스템에 등록된 이용자 목록을 조회하고 검색/필터링할 수 있는 기능 |

### 핵심 비즈니스 개념

- **이용자 (User)**: 시스템에 등록된 사용자 계정
- **Space**: 멀티테넌시 기반의 독립된 공간 (현재 Space 내 이용자만 조회)
- **역할 (Role)**: 이용자에게 부여된 권한 역할
- **분류 (Category)**: 이용자를 카테고리로 분류
- **그룹 (Group)**: 이용자를 그룹으로 묶어 관리

### 시스템 경계

```
┌─────────────────────────────────────────────────────────────┐
│                    Admin Web Application                     │
├─────────────────────────────────────────────────────────────┤
│  [이용자 목록 화면]                                           │
│   - 검색/필터 입력                                            │
│   - 목록 테이블 표시                                          │
│   - 페이지네이션                                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Backend API (기존)                        │
│  - GET /api/users (목록 조회)                                │
│  - GET /api/users/:id (상세 조회)                            │
└─────────────────────────────────────────────────────────────┘
```

## L1: 사용자 (Actor)

### 사용자 정의

| ID | 사용자 | 역할 | 주요 행동 |
|----|--------|------|----------|
| USR-L1-ACT-001 | 관리자 | ADMIN | 이용자 목록을 조회하고 검색/필터링 수행 |

### 사용자 특성

#### 관리자 (ADMIN)

- **목표**: 시스템 내 이용자 현황 파악 및 특정 이용자 검색
- **기술 수준**: 기본적인 관리자 화면 사용 가능
- **접근 권한**: 현재 Space 내 이용자 조회 권한 (CASL: `user.read`)

## L2: 사용자 목표 (Goal)

### 목표 정의

| ID | 목표 | 사용자 | 우선순위 | 설명 |
|----|------|--------|----------|------|
| USR-L2-GOL-001 | 이용자 목록 조회 | 관리자 | 높음 | 등록된 이용자 목록을 한눈에 파악 |
| USR-L2-GOL-002 | 이용자 검색 | 관리자 | 높음 | 이름/이메일/전화번호로 특정 이용자 검색 |
| USR-L2-GOL-003 | 이용자 필터링 | 관리자 | 중간 | 역할/상태/분류/그룹별 이용자 필터링 |
| USR-L2-GOL-004 | 이용자 정렬 | 관리자 | 낮음 | 가입일/이름/이메일 기준 정렬 |

### 목표 상세

#### USR-L2-GOL-001: 이용자 목록 조회

**동기**: 관리자가 시스템 내 이용자 현황을 파악해야 함

**성공 기준**:
- 페이지당 20명씩 이용자 목록 표시
- 기본 정보 (이름, 이메일, 전화번호, 역할, 상태) 확인 가능
- 페이지 이동을 통해 전체 목록 탐색 가능

#### USR-L2-GOL-002: 이용자 검색

**동기**: 특정 이용자를 빠르게 찾아야 함

**성공 기준**:
- 이름, 이메일, 전화번호로 통합 검색
- 실시간 검색 결과 반영
- 검색 결과 없음 메시지 표시

#### USR-L2-GOL-003: 이용자 필터링

**동기**: 특정 조건의 이용자 그룹을 파악해야 함

**성공 기준**:
- 역할별 필터 (복수 선택 가능)
- 상태별 필터 (활성/비활성/삭제됨)
- 분류별 필터 (단일 선택)
- 그룹별 필터 (복수 선택 가능)
- 가입일 범위 필터

#### USR-L2-GOL-004: 이용자 정렬

**동기**: 원하는 기준으로 정렬된 목록 확인

**성공 기준**:
- 정렬 기준: 가입일, 이름, 이메일, 번호
- 정렬 순서: 오름차순/내림차순 선택
