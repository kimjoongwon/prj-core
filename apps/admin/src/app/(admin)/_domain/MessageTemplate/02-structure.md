# L3-L4: 기능, 화면

## 이전 레이어 요약 (L0-L2)

- **L0 Context**: Email/SMS/Push 채널의 템플릿 관리, 변수 치환 미리보기, 테스트 발송
- **L1 Actors**: 시스템 관리자 (FULL_ACCESS) - 전체 템플릿 CRUD/미리보기/테스트, Space 관리자 (MANAGE) - 조회 전용 (향후 확장)
- **L2 Goals**:
  - GOL-001: 템플릿 목록 조회 (유형별 필터, 검색, 활성/비활성 필터)
  - GOL-002: 템플릿 상세 확인 (내용 + 변수 목록)
  - GOL-003: 템플릿 등록 (유형 선택, 내용 작성, 변수 정의)
  - GOL-004: 템플릿 수정
  - GOL-005: 템플릿 삭제
  - GOL-006: 템플릿 활성/비활성 토글
  - GOL-007: 템플릿 미리보기 (변수 치환 렌더링)
  - GOL-008: 발송 테스트 (수신자 지정 발송)
  - GOL-009: 변수 관리 (추가/수정/삭제)

---

## 템플릿 유형별 특성

| 유형 | 제목(subject) | 본문(content) | 비고 |
|------|:---:|:---:|------|
| EMAIL | O | O (HTML) | HTML 편집 지원, 긴 본문 가능 |
| SMS | X | O (텍스트) | 텍스트만, 글자수 제한 표시 (90바이트/장) |
| PUSH | O | O (텍스트) | 제목 50자, 본문 200자 이내 |

#### MT-L3-FEA-001: 템플릿 목록 표시

**설명**: 등록된 템플릿을 DataGrid로 표시합니다.

**표시 컬럼**:

| 컬럼 | 필드 | 너비 | 정렬 | 설명 |
|------|------|------|------|------|
| 코드 | code | 180px | - | 시스템 고유 코드 (예: `WELCOME_EMAIL`) |
| 이름 | name | 200px | 지원 | 템플릿 한글 이름 |
| 유형 | type | 100px | - | EMAIL/SMS/PUSH Badge 표시 |
| 활성 | isActive | 80px | - | Switch 토글 (인라인 변경 가능) |
| 설명 | description | 250px | - | 설명 (말줄임) |
| 등록일 | createdAt | 120px | 지원 | YYYY-MM-DD 형식 |

**페이지네이션**: 페이지당 20건, 크기 변경 10/20/50

- 이름/코드 필드에서 부분 일치 검색
- 검색어 초기화 버튼 제공

#### MT-L3-FEA-005: 템플릿 상세 정보 표시

**설명**: 특정 템플릿의 기본 정보와 유형별 콘텐츠를 표시합니다.

**표시 섹션**:
1. **기본 정보**: 코드, 이름, 유형, 설명, 활성 상태 (Switch 토글), 생성일, 수정일
2. **콘텐츠**: 유형별로 다르게 표시
   - EMAIL: 제목(subject) + HTML 본문 렌더링 미리보기
   - SMS: 본문(content) + 바이트 수 표시
   - PUSH: 제목(subject) + 본문(content)
3. **변수 목록**: FEA-006으로 분리

#### MT-L3-FEA-006: 템플릿 변수 목록 표시

**설명**: 상세 화면 내에서 해당 템플릿에 정의된 변수 목록을 표시합니다.

**표시 컬럼**:

| 컬럼 | 필드 | 너비 | 설명 |
|------|------|------|------|
| 변수명 | name | 160px | `{{userName}}` 형태로 표시 |
| 설명 | description | 200px | 변수 한글 설명 |
| 기본값 | defaultValue | 150px | 미입력 시 사용되는 기본값 |
| 필수 | isRequired | 80px | 필수 여부 Badge |

#### MT-L3-FEA-007: 템플릿 등록 폼

**설명**: 새 템플릿을 등록합니다.

**필드**:

| 필드 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| type | Select | O | 유형 선택 (EMAIL/SMS/PUSH), 선택 후 변경 불가 |
| code | Text Input | O | 고유 코드 (영문 대문자+언더스코어, unique) |
| name | Text Input | O | 템플릿 이름 (한글) |
| description | Textarea | X | 설명 |
| subject | Text Input | 조건부 | 제목 (EMAIL, PUSH일 때 필수) |
| content | Textarea/HTML Editor | O | 본문 (EMAIL: HTML 에디터, SMS/PUSH: Textarea) |

**유형별 폼 동적 변환**:
- EMAIL 선택 시: subject(필수) + content(HTML 에디터)
- SMS 선택 시: content(Textarea) + 바이트 수 카운터
- PUSH 선택 시: subject(필수, 50자 제한) + content(Textarea, 200자 제한)

**하단에 변수 관리 섹션 포함** (FEA-013)

---

#### MT-L3-FEA-008: 템플릿 수정 폼

**설명**: 기존 템플릿을 수정합니다.

**제약사항**:
- code: 수정 불가 (읽기 전용)
- type: 수정 불가 (읽기 전용)
- name, description, subject, content: 수정 가능
- 기존 데이터가 폼에 미리 채워짐

**하단에 변수 관리 섹션 포함** (FEA-013)

---

#### MT-L3-FEA-009: 템플릿 삭제

**설명**: 템플릿을 소프트 삭제합니다.

**동작**:
1. 삭제 버튼 클릭 시 확인 다이얼로그 표시 ("이 템플릿을 삭제하시겠습니까? 관련 변수도 함께 삭제됩니다.")
2. 확인 시 DELETE API 호출 (소프트 삭제)
3. 삭제 후 목록 화면으로 이동 및 목록 갱신

---

#### MT-L3-FEA-010: 템플릿 활성/비활성 토글

**설명**: 상세 화면에서 템플릿의 활성 상태를 즉시 전환합니다.

**동작**:
- 기본 정보 섹션의 활성 상태 옆 Switch 컴포넌트
- 클릭 시 PATCH API 호출 → 즉시 반영
- 비활성화 시 "비활성화된 템플릿은 발송에 사용되지 않습니다" 안내 표시

---

#### MT-L3-FEA-011: 템플릿 미리보기

**설명**: 정의된 변수를 샘플 데이터로 치환한 렌더링 결과를 모달로 표시합니다.

**동작**:
1. 상세 화면에서 "미리보기" 버튼 클릭
2. 모달 열림: 정의된 변수별 입력 필드 표시 (기본값이 있으면 미리 채워짐)
3. "미리보기 실행" 클릭 시 POST API 호출
4. 치환 결과 렌더링:
   - EMAIL: HTML 렌더링 (iframe 또는 shadow DOM)
   - SMS: 텍스트 + 바이트 수 + 장수 계산
   - PUSH: 제목 + 본문 카드 형태
5. 미치환 변수(`{{...}}`) 잔존 시 경고 배지 표시

---

#### MT-L3-FEA-012: 발송 테스트

**설명**: 작성한 템플릿을 실제로 테스트 발송합니다.

**동작**:
1. 상세 화면에서 "테스트 발송" 버튼 클릭
2. 모달 열림: 유형별 수신자 입력 필드 + 변수 값 입력 필드
3. 수신자 입력:
   - EMAIL: 이메일 주소 입력
   - SMS: 전화번호 입력
   - PUSH: 디바이스 토큰 또는 사용자 검색/선택
4. "발송" 클릭 시 POST API 호출
5. 결과 표시: 성공/실패 + 오류 메시지 (실패 시)

---

#### MT-L3-FEA-013: 변수 추가/수정/삭제

**설명**: 등록/수정 폼 하단에서 템플릿 변수를 인라인으로 관리합니다.

**인라인 테이블 컬럼**:

| 컬럼 | 필드 | 타입 | 필수 | 설명 |
|------|------|------|:----:|------|
| 변수명 | name | Text Input | O | 영문 카멜케이스 (예: `userName`) |
| 설명 | description | Text Input | X | 한글 설명 |
| 기본값 | defaultValue | Text Input | X | 미입력 시 기본값 |
| 필수 | isRequired | Switch | X | 필수 여부 (기본: false) |
| 액션 | - | Button | - | 삭제 버튼 |

**동작**:
- "+ 변수 추가" 버튼으로 새 행 추가
- 행 내에서 직접 수정
- 삭제 버튼 클릭 시 해당 행 제거 (본문에서 사용 중이면 경고 표시)
- 변수명 규칙: 영문 카멜케이스 (`/^[a-zA-Z][a-zA-Z0-9]*$/`)
- 본문 내 `{{변수명}}` 패턴과 변수 목록 간 정합성 검증 (경고 수준)

**권한 체크**: `can('read', 'template')` - FULL_ACCESS

**유효성 검증**:

- code: 필수, 영문 대문자+언더스코어만 허용 (`/^[A-Z][A-Z0-9_]*$/`), 중복 불가 (API 검증)
- name: 필수
- subject: EMAIL/PUSH일 때 필수, PUSH는 50자 제한
- content: 필수, SMS는 바이트 수 경고, PUSH는 200자 제한
- 변수명: 영문 카멜케이스 (`/^[a-zA-Z][a-zA-Z0-9]*$/`), 목록 내 중복 불가

**등록 후 동작**: 상세 화면(`/templates/[templateId]`)으로 이동

**권한 체크**: `can('create', 'template')` - FULL_ACCESS 전용

#### MT-L4-SCR-004: 템플릿 수정 화면

**경로**: `/templates/[templateId]/edit`

**레이아웃**: 등록 화면(SCR-003)과 동일한 구조이나 기존 데이터를 prefill

**제약사항**:
- type: 수정 불가 (읽기 전용, Badge 표시)
- code: 수정 불가 (읽기 전용, 텍스트 표시)
- name, description, subject, content: 수정 가능
- 변수: 기존 변수 목록 prefill, 추가/수정/삭제 가능

**수정 후 동작**: 상세 화면(`/templates/[templateId]`)으로 이동

**권한 체크**: `can('update', 'template')` - FULL_ACCESS 전용
