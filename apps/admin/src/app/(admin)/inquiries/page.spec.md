## 사용자 시나리오

1. 관리자가 문의 목록 페이지에 접근하여 전체 문의 현황을 파악한다
2. 필터(카테고리, 채널, 상태, 우선순위)를 사용하여 원하는 문의를 검색한다
3. 검색어를 입력하여 특정 고객명이나 문의 제목으로 검색한다
4. 문의 행을 클릭하여 상세 페이지로 이동한다
5. "문의 접수" 버튼을 클릭하여 새 문의를 수동 접수한다
6. SLA 현황 및 금일 통계를 확인하여 응답/해결 성과를 모니터링한다
