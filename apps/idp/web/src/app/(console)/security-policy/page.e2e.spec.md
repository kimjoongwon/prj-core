# security-policy E2E 기획서

> 생성일: 2026-03-23
> 타입: e2e
> 위치: apps/idp/web/src/app/(console)/security-policy/page.e2e.ts

## 역할

IDP 보안 정책 화면이 로그인 직후에도 안정적으로 렌더링되고 저장 흐름이 복수 테스트 병렬 실행 환경에서도 깨지지 않는지 검증합니다.

## 시나리오

| ID | 설명 |
|----|------|
| E2E-001 | 로그인 후 보안 정책 타이틀과 설명 텍스트가 노출되어야 한다 |
| E2E-002 | 저장 버튼이 항상 렌더링되어야 한다 |
| E2E-003 | 비밀번호/잠금/세션 섹션 필드가 순서대로 표시되어야 한다 |
| E2E-004 | 저장 버튼 클릭 시 성공 메시지가 표시되어야 한다 |
