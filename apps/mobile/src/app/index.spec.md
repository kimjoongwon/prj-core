# mobile index page 기획서

> 생성일: 2026-04-08
> 타입: page
> 위치: apps/mobile/src/app/index.tsx

## 역할

모바일 앱의 기본 엔트리 화면으로, 템플릿 예제 대신 `"빈 화면"` 텍스트만 표시합니다.

## 구성 요소

| 항목 | 설명 |
|------|------|
| centered container | 화면 중앙 정렬의 단순 컨테이너 |
| label text | `"빈 화면"` 고정 문구 |

## 규칙

- Expo 템플릿에서 제공한 예제 카드, 탭, 가이드 문구를 남기지 않습니다.
- 기본 화면은 데모가 아닌 빈 상태를 명확히 보여주는 최소 UI만 유지합니다.
