# 모아핏 신규 입사자 온보딩 위키

> 본 문서는 모아핏(가상의 피트니스 예약 스타트업)의 내부 온보딩 위키 예시입니다.
> Dolmen 데모의 문서 검색(RAG)·평가용 원천 문서로, 날짜·숫자·조건은 평가 시나리오를 위해
> 의도적으로 배치되었습니다. 실제 회사가 아닙니다.

## 1. 회사 소개

모아핏은 2021년 5월에 설립된 피트니스 클래스 예약 플랫폼입니다. 사용자는 모아핏 앱으로
제휴 헬스장·요가원·필라테스 스튜디오의 클래스를 간편하게 예약할 수 있습니다.

- 서비스 출시: 2022년 3월
- 가입 회원 수: 2024년 12월 기준 42만 명
- 제휴 시설 수: 1,850곳 (2025년 6월 기준)
- 본사: 서울시 강남구 테헤란로
- 사업 영역: 클래스 예약, 멤버십 구독, 기업 복지 제휴

## 2. 조직 구조

모아핏은 5개 본부 체계로 운영됩니다.

| 본부 | 담당 | 산하 팀 |
| --- | --- | --- |
| 플랫폼본부 | 앱·웹 서비스 개발 | 프론트엔드팀, 백엔드팀, 데이터팀 |
| 사업본부 | 제휴·영업 | 제휴영업팀, 파트너성장팀 |
| 운영본부 | 고객 지원·시설 관리 | 고객지원팀, 시설운영팀 |
| 마케팅본부 | 브랜드·성장 | 브랜드팀, 퍼포먼스팀 |
| 경영지원본부 | 인사·재무·법무 | 인사팀(HR), 재무팀, 법무팀 |

신규 입사자의 온보딩 담당은 입사 팀의 팀장과 인사팀의 온보딩 매니저입니다.
온보딩 관련 문의는 인사팀 온보딩 매니저(내선 1204)로 연락하세요.

## 3. 근무 정책

### 3.1 근무 시간과 코어타임

- 기본 근무 시간: 주 40시간 (월~금)
- 코어타임: 매일 11:00 ~ 16:00 (이 시간에는 회의·협업을 위해 반드시 근무 중이어야 합니다)
- 유연근무: 코어타임 외 구간은 자유롭게 조정할 수 있습니다 (예: 08:00 출근 ~ 17:00 퇴근)
- 점심시간: 12:00 ~ 13:00 (코어타임에서 제외)

### 3.2 재택근무

- 기본 원칙: 주 2일까지 재택근무 가능 (화·목요일 권장)
- 전원 출근일: 매월 첫째 주 월요일은 전사 워크숍·회의가 있어 전원 출근입니다
- 재택 신청: 사내 그룹웨어에서 전날 18:00까지 신청
- 임직원 누구나 사유 불문으로 재택일을 늘리지는 못하며, 유급 휴가와 별개입니다

### 3.3 초과근무

- 초과근무는 사전 승인제입니다. 팀장 승인 없은 초과근무는 수당 산정에서 제외됩니다.
- 주 52시간 상한을 반드시 준수합니다.
- 연장근무 수당: 통상임금의 1.5배 (야간 22:00~06:00은 0.5배 가산)

## 4. 휴가 정책

### 4.1 연차

| 항목 | 내용 |
| --- | --- |
| 부여 | 입사일 기준 연 15일 (1월 1일 기준 근속 80% 이상 시 다음 해 15일) |
| 발생 시기 | 입사 후 3개월 경과 시부터 사용 가능 (3개월 전 사용은 팀장·인사팀 공동 승인 필요) |
| 이월 | 미사용 연차는 다음 해 3월 말까지 이월 가능, 이후 소멸 |
| 반차 | 오전 반차(09:00~13:00), 오후 반차(13:00~18:00)로 각 0.5일 사용 |
| 신청 | 사용 3영업일 전까지 그룹웨어 신청 (팀장 승인) |

### 4.2 특별 휴가

- 리프레시 휴가: 근속 5년마다 5일 + 50만 원 여비 지원
- 결혼: 본인 결혼 시 5일
- 자녀 출산: 배우자 출산 시 10일 (자녀 출생일로부터 90일 이내 사용)
- 병가: 연간 5일까지 유급 (6일째부터 무급, 진단서 필요)
- 여름 휴가: 매년 7월 마지막 주 월~금 3일 전사 단체 휴가 (연차 차감 없음)

### 4.3 시험 삼아 둔 함정 주의

모아핏에는 **생일 반차 제도가 없습니다**. 생일에 쉬려면 일반 연차를 사용해야 합니다.
(이 항목은 "문서에 없는 답변" 시나리오용으로 삽입되었습니다. 답변 생성기는 생일 반차가
있다고 추측해 답하면 안 됩니다.)

## 5. 비용 처리

### 5.1 처리 절차

1. 증빙(세금계산서·현금영수증·신용카드 매출전표) 수취
2. 그룹웨어 "비용처리" 메뉴에서 품의 작성 (사용일, 사유, 증빙 첨부)
3. 팀장 승인 → 재무팀 검토
4. 검토 통과 시 다음 달 10일 지급 계좌로 지급

- 처리 기한: 사용일로부터 30일 이내 품의 (기한 초과 시 팀장 승인 각서 필요)
- 지급 시기: 매달 10일 (10일이 휴일이면 전 영업일)

### 5.2 항목별 한도 (1인 월 기준)

| 항목 | 월 한도 | 비고 |
| --- | --- | --- |
| 야근 식대 | 10만 원 | 야근(20:00 이후) 시 1일 1회, 1만 원 이하 |
| 출장 교통비 | 실비 정액 | 대중교통 실비, 택시는 야간·거동 제한 사유만 |
| 사무용품 | 5만 원 | 5만 원 초과 품목은 팀 단위 공동 구매 |
| 도서·교육 | 15만 원 | 업무 관련 도서, 온라인 강의 |
| 휴대폰 요금 | 5만 원 | 전 직원 일괄 지급 (청구 불필요, 급여에 포함) |

### 5.3 파트타임 강사 비용 (사내 강의)

모아핏은 임직원 웰니스를 위해 사내 필라테스·요가 클래스를 운영하며, 외부 강사를
초빙합니다. 사내 강사비는 다음 기준으로 처리합니다.

- 강사비: 클래스 1회(60분)당 15만 원
- 신청: 시설운영팀(내선 1305)에 2주 전까지 요청
- 결제: 월말 통합 정산, 재무팀이 강사사에게 직접 입금

## 6. 장비와 보안

### 6.1 장비 지급

| 항목 | 기준 |
| --- | --- |
| 노트북 | 개발·디자인 직군 맥북 프로 16인치, 그 외 직군 윈도우 노트북 |
| 모니터 | 27인치 1대 기본 지급 (신청 시 최대 2대) |
| 교체 주기 | 노트북 3년, 모니터 5년 |
| 휴대폰 | 전 직군 지급 없음 (요금 보조만, 월 5만 원) |

- 노트북 분실 시: 즉시 시큐리티팀 보고, 동일 기기 재구입은 본인 부담 30%
- 퇴사 시: 노트북·모니터·사내 보안 카드 반납 (반납 확인 후 최종 퇴사 처리)

### 6.2 보안 수칙

- 비밀번호는 90일마다 변경 (사내 SSO 기준)
- 고객 개인정보는 노션 '고객정보 보안존' 외부 반출 금지
- 해외 출장 시 노트북 사전 신고 (암호화 확인 필요)

## 7. 서비스 운영 정책 (고객 대상)

고객지원팀·시설운영팀은 다음 정책을 기준으로 고객 응대합니다.

### 7.1 클래스 취소 및 환불

| 시점 | 취소료 |
| --- | --- |
| 클래스 시작 24시간 전까지 | 무료 취소 (전액 환불) |
| 클래스 시작 24시간 이내 ~ 2시간 전 | 요금의 50% 취소료 |
| 클래스 시작 2시간 미만 · 노쇼 | 요금의 100% 취소료 |

- 노쇼 3회 누적 시 30일간 클래스 예약 권한 정지
- 시설 사유 취소(강사 급편 등)는 항상 전액 환불 + 다음 예약 10% 할인 쿠폰 제공

### 7.2 멤버십 구독

- 구독 상품: 라이트(월 39,000원), 스탠다드(월 59,000원), 프리미엄(월 89,000원)
- 스탠다드: 월 8회 클래스 예약 가능, 프리미엄: 무제한
- 멤버십 해지: 언제든 가능, 다음 결제일까지 이용 가능 (중도 환불 불가)
- 멤버십 동결: 1년에 최대 2회, 회당 최대 30일 (병역·임신·질병 사유는 횟수 제한 없음)

### 7.3 기업 복지 제휴

- 기업 회원은 인당 월 49,000원 요금제로 스탠다드급 혜택 제공
- 제휴 문의: 사업본부 제휴영업팀 (partners@moafit.example)

## 10. FAQ

**Q. 프론트엔드팀 신입인데 노트북은 뭘 받나요?**
개발 직군은 맥북 프로 16인치를 받습니다. 입사 1일차에 지급됩니다.

**Q. 재택근무는 몇 번까지 가능한가요?**
주 2일까지 가능합니다. 매월 첫째 주 월요일은 전원 출근일이므로 제외됩니다.

**Q. 야근하고 식사를 했는데 비용 처리가 되나요?**
20:00 이후 야근 시 1일 1회, 1만 원 이하 식대를 월 10만 원 한도로 처리할 수 있습니다.

**Q. 클래스를 예약했는데 아파서 못 갈 것 같아요.**
클래스 시작 2시간 전까지 취소하면 50% 취소료만 발생합니다. 2시간 미만이면 100%
취소료가 부과되니 시설운영팀이나 앱에서 미리 취소하세요.

**Q. 회사 휴대폰을 받을 수 있나요?**
휴대폰 지급은 없고, 요금 보조로 월 5만 원이 지급됩니다.

**Q. 입사 2개월 차인데 연차를 쓸 수 있나요?**
원칙적으로 입사 3개월 경과 후부터 사용 가능합니다. 그 이전에 꼭 필요하면
팀장과 인사팀의 공동 승인을 받아야 합니다.
