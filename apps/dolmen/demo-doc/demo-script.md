# Dolmen 데모 시나리오 대본

데모 문서(`onboarding-wiki.md`) 기반 질문 4유형. 각 질문의 근거 절과 기대 답변을
함께 두어, 골드 QA 셋(4주차 성적표)의 원천으로 그대로 확장한다.

## 유형 ① 사실형 — 숫자·조건 하나를 정확히

| 질문 | 근거 절 | 기대 답변 핵심 |
| --- | --- | --- |
| "연차는 며칠 주어지나요?" | 4.1 | 연 15일 |
| "재택근무는 주에 며칠까지 가능한가요?" | 3.2 | 주 2일 |
| "헬스 클래스를 몇 시간 전까지 취소하면 무료인가요?" | 7.1 | 시작 24시간 전까지 무료 |
| "야근 식대 한도가 궁금해요" | 5.2 | 월 10만 원, 1일 1회 1만 원 이하 |
| "코어타임이 언제예요?" | 3.1 | 매일 11:00~16:00 |

## 유형 ② 합성형 — 두 절 이상을 조합해야 답

| 질문 | 결합 근거 | 기대 답변 핵심 |
| --- | --- | --- |
| "주 2회 재택하면서 다니는데, 노트북을 잃어버리면 어떻게 되나요?" | 3.2 + 6.1 | 재택 무관, 시큐리티팀 즉시 보고 + 본인 부담 30% 재구입 |
| "프론트엔드 팀에 들어갈 예정인데 사내 필라테스 클래스를 이끌고 싶어요. 강사비는 어떻게 되나요?" | 6.1 + 5.3 | 맥북 프로 16인치 수령과 무관하게(독립), 강사비는 60분 1회 15만 원, 2주 전 시설운영팀(1305) 신청 |
| "입사 2개월 차에 결혼하는데 휴가는 어떻게 쓰나요?" | 4.1 + 4.2 | 결혼 5일은 즉시 가능, 연차는 3개월 경과 원칙(공동 승인 예외) |
| "고객이 노쇼로 예약 권한이 정지됐다며 항의해요" | 7.1 | 노쇼 3회 누적 시 30일 정지가 규정 |

## 유형 ③ 부재형 — 문서에 없는 답을 요구 (환각 방지 시연)

| 질문 | 기대 동작 |
| --- | --- |
| "생일에 반차 쓸 수 있나요?" | 생일 반차 제도는 없음(4.3 명시) → "없다, 연차를 써야 한다"고 답 |
| "사내 카페 바우처는 어디서 신청하나요?" | 문서에 존재하지 않음 → "근거를 찾을 수 없다"고 답 (지어내면 실패) |
| "회사 셔틀버스 시간표 알려줘" | 문서에 없음 → 근거 없음 답변 |

## 유형 ④ 기억형 — 이전 세션 대화를 기억 (3주차 MemoryTool 연결 후)

| 단계 | 대화 | 기대 동작 |
| --- | --- | --- |
| 세션 A | "노트북 3년마다 바뀐다며? 나는 올해 입사했으니 2028년에 바꾸네" | RAG가 6.1 근거로 답변, 이 대화가 에피소드 메모리에 저장됨 |
| 세션 B (새로 접속) | "지난번에 내가 노트북 언제 바꾼다고 했지?" | 에피소드 메모리 검색 → "2028년에 교체 예정이라고 하셨습니다" |

## 메모

- ③유형은 답변에 "문서에 근거가 없다"는 표현이 반드시 포함되어야 하고, 없는 제도를
  그럴듯하게 만들어내면 채점에서 감점한다(4주차 채점 기준).
- 근거 절 컬럼은 청크 단위 골드 주석(검색 적중률 채점)으로 그대로 사용한다.
