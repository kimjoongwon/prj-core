## 컨텍스트

`introduction`은 자자의 퍼블릭 소개 앱입니다.
목표는 상담 전환이 아니라, AI 중심 개발 방식과 비용 최적화 논리를 명확한 한 페이지 경험으로 전달하는 것입니다.

## Actor

- 제품 제작을 검토하는 대표/PO/PM
- 빠른 MVP 또는 운영 어드민 구축이 필요한 의사결정자
- 기존 외주 방식의 handoff 비용을 줄이고 싶은 팀

## Goal

- 자자의 개발 방식이 왜 빠르고 경제적인지 이해한다.
- AI가 대체하는 레이어와 사람이 책임지는 레이어를 구분해 신뢰를 얻는다.
- 기술 스택과 실행 절차를 보고 팀의 적합성을 판단한다.
