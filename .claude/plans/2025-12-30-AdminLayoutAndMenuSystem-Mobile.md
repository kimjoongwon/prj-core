## 1. 모바일 레이아웃 개요

### 핵심 전략

**데스크톱:** 좌측 사이드바 + 2depth 트리 메뉴
**모바일:** 하단 탭 바(1depth) + 전체 화면 서브메뉴 리스트(2depth)

### 브레이크포인트

- **모바일**: < 768px
- **데스크톱**: >= 768px

---

## 2. 모바일 화면 구조

### 2.1 기본 화면 (1depth 탭만 표시)

```
+----------------------------------------------------------------+
|               [Logo]               [Space▼] [Avatar▼]         |  <- Header (56px)
+----------------------------------------------------------------+
|                                                                |
|                                                                |
|                     페이지 콘텐츠 영역                           |
|                     (스크롤 가능)                               |
|                                                                |
|                                                                |
+----------------------------------------------------------------+
| [대시보드] [사용자] [일정] [파일] [더보기]                        |  <- BottomTab (64px)
+----------------------------------------------------------------+
```

### 2.2 서브메뉴 리스트 화면 (2depth)

```
+----------------------------------------------------------------+
|  [←]  사용자                            [Space▼] [Avatar▼]     |  <- Header with Back
+----------------------------------------------------------------+
|                                                                |
|  사용자 목록                                              >     |
|  --------------------------------------------------------      |
|  프로필 관리                                              >     |
|  --------------------------------------------------------      |
|  분류 관리                                                >     |
|  --------------------------------------------------------      |
|  그룹 관리                                                >     |
|                                                                |
+----------------------------------------------------------------+
| [대시보드] [사용자] [일정] [파일] [더보기]                        |  <- BottomTab
+----------------------------------------------------------------+
```

## 3. 컴포넌트 구성

### 3.1 BottomTab

**역할:**
- 모바일 하단 탭 네비게이션 (1depth 메뉴만)
- 아이콘 + 라벨 세로 배치
- 최대 5개 탭 권장

**스타일:**
- 높이: 64px
- 배경: bg-content1
- 테두리: 상단 구분선
- 활성 탭: primary 색상
- 비활성 탭: 연한 회색
- 데스크톱에서 숨김 (768px 이상)

### 3.2 SubMenuList

**역할:**
- 2depth 메뉴를 전체 화면 리스트로 표시
- 각 항목 클릭 시 페이지 이동
- Header 아래 ~ BottomTab 위 영역 차지

**스타일:**
- 전체 화면 높이
- 배경: bg-background
- 리스트 항목 높이: 56px
- 구분선: 각 항목 하단
- 활성 항목: primary 배경
- 우측: 화살표 아이콘

### 3.3 BackButton

**역할:**
- Header 좌측 뒤로가기 버튼
- SubMenuList 화면에서만 표시

**스타일:**
- 크기: 44x44px (터치 영역)
- 아이콘: 24x24px
- 회색 텍스트
- 호버: 배경색 변경

## 4. 인터랙션 상세

### 4.1 사용자 시나리오

**시나리오 1: 하위 메뉴가 없는 탭 (대시보드)**
1. 사용자가 "대시보드" 탭 클릭
2. 즉시 대시보드 페이지로 이동
3. SubMenuList 표시 없음

**시나리오 2: 하위 메뉴가 있는 탭 (사용자)**
1. 사용자가 "사용자" 탭 클릭
2. SubMenuList 전체 화면 표시 (사용자 목록, 프로필 관리, 분류 관리, 그룹 관리)
3. 사용자가 "사용자 목록" 클릭
4. 사용자 목록 페이지로 이동 + SubMenuList 닫힘

**시나리오 3: 뒤로가기**
1. SubMenuList 화면에서 Header 좌측 뒤로가기 버튼 클릭
2. SubMenuList 닫힘
3. 이전 페이지로 복귀

**시나리오 4: 다른 탭 선택**
1. SubMenuList 화면에서 BottomTab의 다른 탭 클릭
2. 현재 SubMenuList 닫힘
3. 새로운 메뉴의 SubMenuList 또는 페이지 표시

## 5. 터치 인터랙션

### 터치 영역

| 컴포넌트 | 최소 터치 영역 |
|----------|---------------|
| BottomTab 탭 | 48px |
| SubMenuList 항목 | 56px (높이) |
| BackButton | 44x44px |

### 터치 피드백

- 탭/버튼 누름: 배경색 변경 (즉각 피드백)
- 리스트 항목 누름: 배경색 변경

### 스와이프 (선택적)

- 화면 왼쪽 가장자리에서 오른쪽 스와이프: SubMenuList 닫힘
- iOS/Android 네이티브 앱과 유사한 UX

## 7. 성능 최적화 가이드

### 조건부 렌더링
- SubMenuList는 표시 필요 시에만 렌더링
- 불필요한 DOM 생성 방지

### 터치 반응성
- 즉각적인 시각적 피드백
- 300ms 지연 없음

### 애니메이션
- 부드러운 전환 (60fps)
- GPU 가속 활용
