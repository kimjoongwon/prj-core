## 2. UI/UX 가이드라인

### 2.1 반응형 대응

| 화면 크기 | 대응 |
|----------|------|
| Desktop (≥1280px) | 전체 테이블 표시 |
| Tablet (768-1279px) | 일부 컬럼 숨김 (전화번호, 닉네임) |
| Mobile (<768px) | 카드 뷰로 전환 |

### 2.2 로딩 상태

- 테이블: Skeleton 로딩
- 통계 카드: Skeleton 로딩
- 모달: 버튼 로딩 스피너

### 2.3 에러 처리

| 에러 상황 | 대응 |
|----------|------|
| 네트워크 오류 | Toast 알림 + 재시도 버튼 |
| 권한 없음 | 403 페이지 리다이렉트 |
| 데이터 없음 | Empty State 컴포넌트 |
| 유효성 검사 실패 | 필드별 인라인 에러 메시지 |

### 2.4 성능 최적화

- 테이블 가상화 (대량 데이터 시)
- 검색 디바운싱 (300ms)
- 페이지네이션 서버 사이드
- 이미지 lazy loading
