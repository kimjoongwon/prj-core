## 시나리오 1: 메뉴 접근 권한 (RBAC - RoleCategory 기반)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    직군별 메뉴 접근 권한 매트릭스                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  메뉴                │ SUPER │ MANAGER │ TRAINER │ FRONT │ ACCOUNT │ 판단기준 │
│                      │ ADMIN │ (점장)  │(트레이너)│ DESK  │ ANT     │         │
│  ────────────────────┼───────┼─────────┼─────────┼───────┼─────────┼─────────│
│  📊 대시보드          │  ✅   │   ✅    │   ✅    │  ✅   │   ✅    │ ADMIN   │
│  👥 사용자 관리       │  ✅   │   ✅    │   ✅    │  ⚠️   │   ❌    │ 직군별  │
│    ├ 회원 목록        │  ✅   │   ✅    │   ✅    │  ✅   │   ❌    │ TRAINER │
│    ├ 회원 정보 수정   │  ✅   │   ✅    │   ✅    │  ❌   │   ❌    │ TRAINER │
│    └ 직원 관리        │  ✅   │   ✅    │   ❌    │  ❌   │   ❌    │ MANAGER │
│  📅 일정 관리         │  ✅   │   ✅    │   ✅    │  ✅   │   ❌    │ ADMIN   │
│    ├ 세션 운영        │  ✅   │   ✅    │   ✅    │  ❌   │   ❌    │ TRAINER │
│    ├ 예약 접수/변경   │  ✅   │   ✅    │   ✅    │  ✅   │   ❌    │ FRONT   │
│    └ 프로그램 편성    │  ✅   │   ✅    │   ✅    │  ❌   │   ❌    │ TRAINER │
│  💰 정산 관리         │  ✅   │   ✅    │   ❌    │  ❌   │   ✅    │ 특수    │
│    ├ 매출 리포트      │  ✅   │   ✅    │   ❌    │  ❌   │   ✅    │ MANAGER │
│    └ 환불 처리        │  ✅   │   ✅    │   ❌    │  ❌   │   ✅    │ +ACCOUNT│
│  ⚙️ 설정             │  ✅   │   ⚠️    │   ❌    │  ❌   │   ❌    │ 제한적  │
│    ├ 시설 정보        │  ✅   │   ✅    │   ❌    │  ❌   │   ❌    │ MANAGER │
│    ├ 권한 관리        │  ✅   │   ❌    │   ❌    │  ❌   │   ❌    │ SUPER만 │
│    └ 시스템 설정      │  ✅   │   ❌    │   ❌    │  ❌   │   ❌    │ SUPER만 │
│                                                                              │
│  ⚠️ = 일부 기능만 접근 가능                                                    │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

Guard 데코레이터 예시:

@RoleCategories([ADMIN])           // 모든 관리자 접근 (MANAGER, TRAINER, FRONT_DESK, ACCOUNTANT)
@RoleCategories([TRAINER])         // 트레이너만 접근 (회원 정보 수정, 세션 운영)
@RoleCategories([MANAGER])         // 점장만 접근 (직원 관리, 정산)
@RoleCategories([MANAGER, ACCOUNTANT])  // 점장 또는 정산담당 (환불 처리)
```

```

> **Action 기반 필드 가시성 (2026-01-10 업데이트)**
>
> 위 매트릭스는 Action 모델을 통해 구현됩니다:
>
> | Action | 의미 | config |
> |--------|------|--------|
> | `read` | 전체 조회 (✅) | `null` |
> | `read:masked:email` | 이메일 마스킹 (⚠️) | `{ "type": "masking", "preset": "PRESET_EMAIL" }` |

> | `read:hidden` | 숨김 (❌) | `null` |
>

>   "priority": 0

> ```

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         전체 권한 체크 흐름 예시                               │
├─────────────────────────────────────────────────────────────────────────────┤

│     └── JWT 토큰 검증 ✅                                                     │

│     ├── 필요 권한: RoleCategory.MANAGER 이상                                 │
│     ├── 김중원 RoleCategory: MANAGER                                        │
│     └── 결과: ✅ 통과                                                        │
│                                                                              │
│  3️⃣ ABAC 체크 (CaslAbilityFactory)                                          │
│     ├── Role 기반 Ability 조회:                                              │
│     │   └── { action: 'read', subject: 'Reservation',                       │

│     │         priority: 10 }                                                │
│     │                                                                        │
│     ├── 병합 (priority 높은 것 우선):                                        │
│     │   └── 최종: 강남점 + 홍대점 예약 조회 가능                               │
│     │                                                                        │

│                                                                              │
│  4️⃣ 응답                                                                     │
│     └── 강남점 100건 + 홍대점 80건 = 180건 반환                               │
│                                                                              │
