## v7.0 핵심 변경

### 1. FAB (Floating Action Button) 도입

모바일에서 가장 자주 사용하는 기능에 **원터치 접근**:

```
             [👤 회원 검색]
                   ↖
       [📅 빠른 예약]  ←  [⚡FAB]  (클릭 시 팬 확장)
                   ↙
             [📋 오늘 예약]
```

**FAB 액션 (3개):**

| 순서 | 아이콘 | 라벨 | 동작 | 권한 |
|------|--------|------|------|------|
| 1 | CalendarCheck | 오늘 예약 | 오늘 예약 목록 페이지로 이동 | quickAction:todayReservation |
| 2 | CalendarPlus | 빠른 예약 | 예약 생성 모달 오픈 | quickAction:quickReservation |
| 3 | Search | 회원 검색 | 회원 검색 모달 오픈 | quickAction:userSearch |

**FAB 동작:**
- 기본 상태: 번개 아이콘 (⚡)
- 클릭 시: 팬 형태로 3개 액션 버튼 확장
- 외부 클릭: 팬 닫힘
- 스크롤 시: FAB 유지 (항상 표시)

### 2. BottomTab 순서 변경

**사용 빈도 기반 재배치:**

| 기존 | 변경 (v7.0) | 이유 |
|------|-------------|------|
| 대시보드, 사용자, 예약, 알림, 더보기 | 대시보드, **예약**, **회원**, 알림, 더보기 | 예약과 회원이 가장 많이 사용됨 |

## 사용자 시나리오

### 시나리오 1: 트레이너 - 오늘 수업 확인

**상황**: 트레이너가 출근 후 오늘 자신의 수업 스케줄을 확인하고 싶음

**경로 (2가지):**

**A. FAB 사용 (권장)**
1. FAB 클릭 → 팬 확장
2. "오늘 예약" 클릭
3. 오늘 예약 목록 페이지 표시

**B. BottomTab 사용**
1. BottomTab "예약" 탭 클릭
2. SubMenuList 표시 (오늘 예약, 예약 목록, 캘린더, 통계)
3. "오늘 예약" 클릭
4. 오늘 예약 목록 페이지 표시

**탭 수 비교**: FAB 2탭 vs BottomTab 3탭

---

### 시나리오 2: 예약 데스크 - 방문 회원 출석 체크

**상황**: 회원이 카운터에 도착, 출석 체크 필요

**경로:**
1. FAB 클릭 → "회원 검색" 클릭
2. 회원 검색 모달에서 이름/전화번호 입력
3. 검색 결과에서 회원 선택
4. 회원 상세에서 "오늘 예약" 확인
5. "출석" 버튼 클릭

---

### 시나리오 3: 예약 데스크 - 워크인 회원 즉석 예약

**상황**: 예약 없이 방문한 회원이 수업을 신청

**경로:**
1. FAB 클릭 → "빠른 예약" 클릭
2. 예약 생성 모달 오픈
3. 회원 검색 → 프로그램 선택 → 시간 선택
4. 예약 생성 완료

---

### 시나리오 4: BottomTab에서 하위 메뉴가 없는 탭

**상황**: 대시보드 확인

**경로:**
1. BottomTab "대시보드" 클릭
2. 즉시 대시보드 페이지로 이동 (SubMenuList 없음)

---

### 시나리오 5: BottomTab에서 하위 메뉴가 있는 탭

**상황**: 회원 등급 관리 페이지로 이동

**경로:**
1. BottomTab "회원" 클릭
2. SubMenuList 전체 화면 표시 (회원 목록, 등급 관리, 탈퇴 회원)
3. "등급 관리" 클릭
4. 등급 관리 페이지로 이동 + SubMenuList 닫힘

---

### 시나리오 6: 더보기 탭

**상황**: 시설 정보 수정 필요

**경로:**
1. BottomTab "더보기" 클릭
2. SubMenuList에 나머지 1depth 표시:
   - 문의
   - 콘텐츠
   - 템플릿
   - 시설
   - 관리자
   - 역할/권한
3. "시설" 클릭
4. 시설의 2depth SubMenuList 표시 (시설 정보, 프로그램, 장비/시설물)
5. "시설 정보" 클릭
6. 시설 정보 페이지로 이동

## 컴포넌트 구성

### FAB (FloatingActionButton)

**역할:** 모바일에서 자주 사용하는 기능 원터치 접근

**상태:**
| 상태 | 표시 |
|------|------|
| 닫힘 | 번개 아이콘 (⚡) 단일 버튼 |
| 열림 | 팬 형태 3개 액션 버튼 + 오버레이 |

**스타일:**
- 위치: 우측 하단, BottomTab 위 16px
- 크기: 56x56px (메인 버튼)
- 배경: primary 색상
- 그림자: shadow-lg
- 액션 버튼: 48x48px, 라벨 포함

**애니메이션:**
- 열림: 메인 버튼 45도 회전 + 액션 버튼 팬 확장
- 닫힘: 역방향 애니메이션

### BottomTab

**역할:** 1depth 메뉴 네비게이션

**탭 구성 (v7.0):**
| 순서 | ID | 라벨 | 아이콘 | 하위 메뉴 |
|------|-----|------|--------|----------|
| 1 | dashboard | 대시보드 | LayoutDashboard | 없음 (바로 이동) |
| 2 | reservations | 예약 | CalendarCheck | 있음 |
| 3 | users | 회원 | Users | 있음 |
| 4 | notifications | 알림 | Bell | 있음 |
| 5 | more | 더보기 | MoreHorizontal | 나머지 1depth 표시 |

**스타일:**
- 높이: 64px
- 배경: bg-content1
- 테두리: 상단 구분선
- 탭: 아이콘 + 라벨 세로 배치
- 활성 탭: primary 색상
- 비활성 탭: text-default-400

### SubMenuList

**역할:** 2depth 메뉴 전체 화면 리스트

**스타일:**
- 전체 화면 (Header 아래 ~ BottomTab 위)
- 배경: bg-background
- 리스트 항목: 56px 높이
- 구분선: 각 항목 하단
- 활성 항목: bg-primary/10
- 우측: 화살표 아이콘 (>)

### Header (모바일)

**일반 페이지:**
```
[Logo]                              [🔔Badge] [Space▼] [Avatar]
```

**SubMenuList 화면:**
```
[←] 회원                            [🔔Badge] [Space▼] [Avatar]
```
