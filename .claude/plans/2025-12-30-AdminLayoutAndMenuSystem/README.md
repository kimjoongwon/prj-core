## 개요

Admin 앱의 레이아웃 및 메뉴 시스템을 **모바일 사용자(예약 관리 데스크, 트레이너) 중심**으로 재설계합니다.

### 핵심 사용자 및 시나리오

| 역할 | 주요 사용 환경 | 핵심 기능 |
|------|--------------|----------|
| 예약 관리 데스크 | 모바일 (카운터) | 예약 확인, 출석 체크, 회원 조회 |
| 트레이너 | 모바일 (현장) | 예약 확인, 출석 체크, 회원 정보 |
| 관리자 | 데스크톱 (사무실) | 전체 관리, 통계, 설정 |

### 레이아웃 전략

| 플랫폼 | 브레이크포인트 | 레이아웃 | 최적화 포인트 |
|--------|---------------|----------|-------------|
| 데스크톱 | >= 768px | Header + 좌측 Sidebar (항상 펼침) + Main | 전체 메뉴 구조 한눈에 파악 |
| 모바일 | < 768px | Header + Main + BottomTab + FAB | 자주 쓰는 기능 원터치 접근 |

### 진입/이탈 조건

- **진입**: Space 선택 완료 + 관리자 인증 완료
- **이탈**: 로그아웃 또는 Space 재선택

## 메뉴 계층 구조 (3 Depth)

```
1depth (사이드바 메인 메뉴)
├── 2depth (사이드바 하위 메뉴) → 클릭 시 페이지 이동
│   └── 3depth (페이지 내 상단 탭) → 같은 페이지 내 탭 전환
```

**예시:**
```
회원 (1depth)
├── 회원 목록 (2depth) → /users
│   └── 상단 탭: [전체] [활성] [휴면] [탈퇴대기] (3depth)
├── 등급 관리 (2depth) → /users/grades
│   └── 상단 탭: [등급 목록] [등급 혜택] (3depth)
└── 탈퇴 회원 (2depth) → /users/withdrawn
```

## v7.0 핵심 변경사항

### 1. DDD 기반 메뉴 재설계 (설정 분리)

**기존 "설정" 메뉴를 도메인별로 분리:**

| 기존 (설정 내) | 변경 (별도 1depth) | 도메인 |
|---------------|-------------------|--------|
| 시설 정보 | **시설** (grounds) | Space/Ground |
| 관리자 관리 | **관리자** (admins) | Admin |
| 권한 관리 | **역할/권한** (roles) | Role/Ability |
| 시스템 설정 | 제거 또는 시설로 통합 | - |

### 2. 데스크톱 Sidebar - 모든 메뉴 항상 펼침

- **기존**: Accordion 방식 (토글)
- **변경**: 모든 2depth 메뉴가 항상 보이는 상태

### 3. 모바일 FAB (Floating Action Button) 도입

- 클릭 시 팬 형태로 3개 액션 확장
- 오늘 예약, 빠른 예약, 회원 검색

### 4. BottomTab 재구성

- 사용 빈도 기반 순서 변경: 대시보드 → **예약** → **회원** → 알림 → 더보기
