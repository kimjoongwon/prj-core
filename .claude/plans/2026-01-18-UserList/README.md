# 회원 목록 화면 기획서

**플랫폼:** Admin Web
**작성일:** 2026-01-18

---

## 개요

시설(Ground)에 등록된 회원 정보를 관리하기 위한 화면입니다. 관리자가 회원의 상태를 파악하고, 회원 정보를 조회/등록/수정/삭제할 수 있습니다.

### 핵심 기능

| 기능 | 설명 |
|------|------|
| 목록 조회 | 탭별 상태 필터링 (전체/활성/휴면/탈퇴대기) |
| 검색 | 이름, 이메일, 전화번호 통합 검색 |
| 등록/수정/삭제 | CRUD 전체 지원 |
| 일괄 작업 | 선택 항목 일괄 상태 변경/삭제 |

### 라우팅 경로

| 탭 | 경로 | 설명 |
|----|------|------|
| 전체 | `/users` | 모든 회원 |
| 활성 | `/users/active` | 활성 상태 회원 |
| 휴면 | `/users/dormant` | 휴면 상태 회원 |
| 탈퇴대기 | `/users/pending-withdrawal` | 탈퇴 대기 중인 회원 |

### CRUD 화면 구성

| 기능 | 화면 | 경로 |
|------|------|------|
| 목록 (Read) | 회원 목록 | `/users` |
| 상세 (Read) | 회원 상세 | `/users/[id]` |
| 등록 (Create) | 회원 등록 | `/users/new` |
| 수정 (Update) | 회원 수정 | `/users/[id]/edit` |
| 삭제 (Delete) | 삭제 모달 | - |
