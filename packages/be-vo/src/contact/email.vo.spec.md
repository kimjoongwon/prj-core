# Email VO 기획서

> 생성일: 2026-02-19
> 수정일: 2026-02-19
> 타입: vo
> 위치: packages/be-vo/src/contact/email.vo.ts

## 역할

이메일 주소를 값 객체로 캡슐화합니다. RFC 5322 표준 형식을 검증하고, 입력 시 자동으로 소문자로 정규화하여 일관된 형식을 보장합니다. 도메인 파트와 로컬 파트 추출 기능도 제공합니다.

## Props

| 필드 | 타입 | 설명 |
|------|------|------|
| value | string | 소문자로 정규화된 이메일 주소 |

## 유효성 규칙

| 규칙 | 에러 메시지 |
|------|------------|
| value 필수 | "이메일은 필수입니다." |
| RFC 5322 형식 검증 | "유효하지 않은 이메일 형식입니다: {value}" |

## 이메일 정규식

```
/^[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+@[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?(?:\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*$/
```

RFC 5322 기반 검증으로 일반적인 이메일 형식을 모두 허용합니다.

## 팩토리 메서드

| 메서드 | 파라미터 | 설명 |
|--------|----------|------|
| `Email.create(email)` | string | trim + toLowerCase 후 유효성 검사하여 생성 |

## 도메인 메서드

| 메서드 | 반환 | 설명 |
|--------|------|------|
| `get value` | string | 정규화된 이메일 문자열 반환 |
| `getDomain()` | string | "@" 이후 도메인 파트 반환 (예: "gmail.com") |
| `getLocalPart()` | string | "@" 이전 로컬 파트 반환 (예: "user") |
| `toString()` | string | 이메일 문자열 그대로 반환 |

## 정규화 규칙

- `email.trim()` - 앞뒤 공백 제거
- `email.toLowerCase()` - 소문자 변환
- User와 같은 DB 저장 시에도 소문자로 저장
