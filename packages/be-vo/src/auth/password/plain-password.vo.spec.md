# PlainPassword VO 기획서

> 생성일: 2026-02-19
> 수정일: 2026-02-19
> 타입: vo
> 위치: packages/be-vo/src/auth/password/plain-password.vo.ts

## 역할

사용자가 입력한 평문 비밀번호를 값 객체로 캡슐화합니다. 비밀번호 정책(길이, 허용 문자)을 강제하고, `toString()`에서 `********`로 마스킹하여 로그 노출을 방지합니다. `HashedPassword.fromPlain()`에 전달하여 해싱하는 용도로 사용됩니다.

## Props

| 필드 | 타입 | 설명 |
|------|------|------|
| value | string | 평문 비밀번호 문자열 |

## 유효성 규칙

| 규칙 | 에러 메시지 |
|------|------------|
| value 필수 | "비밀번호는 필수입니다." |
| 최소 8자 이상 | "비밀번호는 최소 8자 이상이어야 합니다." |
| 최대 72자 이하 (bcrypt 제한) | "비밀번호는 최대 72자를 초과할 수 없습니다." |
| 허용 문자만 사용 (영문, 숫자, 특수문자) | "비밀번호는 영문, 숫자, 특수문자만 포함할 수 있습니다." |

## 허용 문자 정규식

```
/^[\d!#$%&*@A-Z^a-z]*$/
```

- 영문 대소문자 (A-Z, a-z)
- 숫자 (0-9)
- 특수문자 (!#$%&*@^)

## 상수

| 상수 | 값 | 설명 |
|------|-----|------|
| MIN_LENGTH | 8 | 최소 비밀번호 길이 |
| MAX_LENGTH | 72 | 최대 비밀번호 길이 (bcrypt 한계) |
