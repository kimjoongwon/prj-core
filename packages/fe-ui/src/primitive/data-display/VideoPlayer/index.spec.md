# VideoPlayer UI 컴포넌트 기획서

> 생성일: 2026-02-18
> 타입: ui
> 위치: packages/fe-ui/src/primitive/data-display/VideoPlayer/

## 역할

모달에서 비디오를 재생하는 컴포넌트. 재생/일시정지, 전체화면 전환 기능을 제공한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[ 모달 열림 - 재생 중 (isPlaying=true) ]

  ╔══════════════════════════════════════════╗
  ║                                          ║
  ║  ┌──────────────────────────────────┐   ║
  ║  │                                  │   ║
  ║  │         [  비디오 화면  ]         │   ║
  ║  │                                  │   ║
  ║  └──────────────────────────────────┘   ║
  ║                                          ║
  ║  [ ⏸ 일시정지 ]      [ ⛶ 전체화면 ]   ║  ← 컨트롤 버튼
  ║                                          ║
  ╚══════════════════════════════════════════╝

[ 모달 열림 - 일시정지 (isPlaying=false) ]

  ╔══════════════════════════════════════════╗
  ║                                          ║
  ║  ┌──────────────────────────────────┐   ║
  ║  │                                  │   ║
  ║  │         [  비디오 화면  ]         │   ║
  ║  │              ▶                   │   ║  ← 중앙 재생 버튼
  ║  └──────────────────────────────────┘   ║
  ║                                          ║
  ║  [ ▶ 재생 ]          [ ⛶ 전체화면 ]   ║
  ║                                          ║
  ╚══════════════════════════════════════════╝

[ 전체화면 모드 (isFullscreen=true) ]

╔════════════════════════════════════════════════╗
║                                                ║
║  ┌──────────────────────────────────────────┐  ║
║  │                                          │  ║
║  │           [  비디오 화면  ]               │  ║  ← 전체 화면 확장
║  │                                          │  ║
║  └──────────────────────────────────────────┘  ║
║                                                ║
║  [ ⏸ 일시정지 ]        [ ⊡ 창 복원 ]        ║  ← Minimize 아이콘
║                                                ║
╚════════════════════════════════════════════════╝

[ 모달 닫힘 (isOpen=false) ]

  (모달 숨김, 비디오 정지 및 시작점 리셋)
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 재생 중 | 비디오 재생 + Pause 버튼 |
| 일시정지 | 비디오 정지 + Play 버튼 |
| 전체화면 | 모달 전체 확장 + Minimize 버튼 |
| 모달 닫힘 | 화면 없음 (비디오 리셋) |

## Props

```typescript
interface VideoPlayerProps {
  /** 비디오 소스 URL */
  src: string;
  /** 모달 열림 상태 */
  isOpen: boolean;
  /** 모달 닫기 핸들러 */
  onClose: () => void;
}
```

## 상태

| 상태 | 동작 |
|------|------|
| isPlaying=true | 재생 중, Pause 아이콘 표시 |
| isPlaying=false | 일시정지, Play 아이콘 표시 |
| isFullscreen=true | 전체화면 모드, Minimize 아이콘 |
| isFullscreen=false | 일반 모드, Maximize 아이콘 |
| isOpen=false | 비디오 정지 및 시작점으로 리셋 |

## 내부 의존성

- `lucide-react` (Play, Pause, Maximize, Minimize)
