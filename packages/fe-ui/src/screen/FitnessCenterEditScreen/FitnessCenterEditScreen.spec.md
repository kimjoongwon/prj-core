# FitnessCenterEditScreen

- `FitnessCenterEditScreen`은 FitnessCenter 상세/수정 route가 공유하는 Screen이다.
- route는 `readOnly`로 상세 모드를 결정하고, `title`, `description`, `actions`를 전달한다.
- Screen은 피트니스 센터 편집 form을 사용하며 직접 입력 필드를 소유하지 않는다.
- 수정 모드에서는 피트니스 센터 기본 정보와 Space 콘텐츠 언어만 편집 대상으로 노출한다.
- Company 공통 필드는 별도 읽기 전용 패널이 없으면 화면에서 노출하지 않는다.

## 화면 러프

### Desktop

```text
+--------------------------------------------------------------+
| Header                                                       |
| 피트니스 센터 정보 수정                                      |
| 피트니스 센터 정보와 Space 콘텐츠 언어를 수정합니다.         |
|                                              [actions slot]  |
+--------------------------------------------------------------+
| Section: 피트니스 센터 정보                                  |
| [시설명]                                                     |
| [라벨]                                                       |
| [주소]                                                       |
| [전화번호]                                                   |
| [이메일]                                                     |
| [콘텐츠 언어 Select]                                         |
|                                          [취소] [저장]       |
+--------------------------------------------------------------+
```

### Mobile

```text
+----------------------------------+
| 피트니스 센터 정보 수정          |
| Space 콘텐츠 언어 포함 편집      |
+----------------------------------+
| 시설명                           |
| 라벨                             |
| 주소                             |
| 전화번호                         |
| 이메일                           |
| 콘텐츠 언어                      |
| [취소] [저장]                    |
+----------------------------------+
```

## 조합

| 레이어 | 이름 | 역할 |
| --- | --- | --- |
| form | `FitnessCenterForm` | 피트니스 센터 기본 정보와 Space 콘텐츠 언어 입력 |
| layout | `Screen.Header` | 제목, 설명, 상단 actions 노출 |
| layout | `Section` + `SectionSurface` | 단일 편집 섹션 구조화 |
