# Account Tenant Select Screen

## 목적

- 로그인한 account가 작업할 Space를 선택할 때 사용하는 독립 화면입니다.
- 실제 tenant 조회와 선택 저장은 `AccountTenantSelect`가 소유하며, 이 screen은 안내와 배치만 소유합니다.

## Props 계약

| prop | 설명 |
| --- | --- |
| `eyebrow` | 선택 카드의 짧은 문맥 표시 |
| `title` | 화면의 주 안내 제목 |
| `description` | 선택 결과의 저장 동작을 설명하는 문구 |

## 하위 조합

| 구성 요소 | 책임 |
| --- | --- |
| `ScreenSurface` | viewport 전체의 screen boundary |
| `SectionSurface` + `Section` | 중앙 선택 카드의 표면과 구조 |
| `Typography` | eyebrow와 안내 문구 |
| `AccountTenantSelect` | tenant 조회, 현재 선택 표시, 선택 저장 |

## 상태

- tenant 로딩, 빈 목록, 선택 저장 중 상태는 `AccountTenantSelect`의 자체 계약을 그대로 사용합니다.
- tenant 선택이 완료되면 account bootstrapper가 `/dashboard`로 이동합니다.
