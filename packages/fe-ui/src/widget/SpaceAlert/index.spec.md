# SpaceAlert Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/SpaceAlert/

## 역할

Space가 선택되지 않았을 때 표시되는 모달 Alert입니다. 확인 버튼으로 Space 선택 화면으로 유도합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[기본 모달 Alert]
┌─────────────────────────────────────────────┐
│                                             │
│                 🏢                          │
│                                             │
│          Space 선택 필요                    │
│                                             │
│  서비스 이용을 위해 Space를 선택해주세요.   │
│                                             │
│  ┌───────────────────────────────────────┐  │
│  │          Space 선택하기               │  │
│  └───────────────────────────────────────┘  │
│                                             │
│              [취소/닫기]                     │
│                                             │
└─────────────────────────────────────────────┘

[오버레이 배경 포함]
░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
░░  ┌─────────────────────────────────┐  ░░
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 제목 + 메시지 + 확인 버튼 + 닫기 버튼 |
| onDismiss 없음 | 닫기 버튼 미표시 (필수 선택 유도) |

## Props

```typescript
interface SpaceAlertProps {
  title?: string;           // 기본값: "Space 선택 필요"
  message?: string;         // 기본값: "서비스 이용을 위해 Space를 선택해주세요."
  confirmText?: string;     // 기본값: "Space 선택하기"
  onConfirm?: () => void;
  onDismiss?: () => void;
}
```

## 하위 UI 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| Button (커스텀) | 확인/닫기 버튼 |
| Text (커스텀) | 제목/메시지 텍스트 |
