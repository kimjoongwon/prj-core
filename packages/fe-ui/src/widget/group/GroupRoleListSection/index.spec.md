# GroupRoleListSection Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/group/GroupRoleListSection/

## 역할

그룹에 소속된 역할 목록을 읽기 전용 테이블로 표시합니다. 역할 식별자(링크), 표시명, 시스템 여부(Chip) 컬럼을 제공합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
  ┌──────────────────────────┬──────────────────┬────────────┐
  │ 역할 식별자               │ 표시명            │ 시스템 여부 │
  ├──────────────────────────┼──────────────────┼────────────┤
  │ 🔗 FULL_ACCESS           │ 전체 접근         │ [시스템]   │
  ├──────────────────────────┼──────────────────┼────────────┤
  │ 🔗 MANAGE                │ 관리자            │ [시스템]   │
  ├──────────────────────────┼──────────────────┼────────────┤
  │ 🔗 custom-editor         │ 편집자            │            │
  └──────────────────────────┴──────────────────┴────────────┘

  --- 로딩 중 ---

  ┌──────────────────────────┬──────────────────┬────────────┐
  │ 역할 식별자               │ 표시명            │ 시스템 여부 │
  ├──────────────────────────┼──────────────────┼────────────┤
  │ ████████████████         │ ████████         │  ██████    │
  ├──────────────────────────┼──────────────────┼────────────┤
  │ ████████████             │ ██████           │            │
  └──────────────────────────┴──────────────────┴────────────┘

  --- 데이터 없음 ---

  ┌──────────────────────────────────────────────────────────┐
  │                  소속된 역할이 없습니다                   │
  └──────────────────────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 시스템 역할 | 시스템 여부 셀에 success 색상 [시스템] Chip 표시 |
| 일반 역할 | 시스템 여부 셀 비어있음 (또는 default Chip) |
| 로딩 중 (isLoading=true) | 행 단위 Skeleton 표시 |
| 데이터 없음 | 빈 테이블 |

## Props

```typescript
interface GroupRoleListSectionProps {
  roleAssociations: GroupRoleItem[];
  isLoading?: boolean;          // 기본값: false
  rolesBasePath?: string;       // 기본값: "/roles"
}

interface GroupRoleItem {
  id: string;
  roleId: string;
  role?: {
    id: string;
    name: string;
    displayName?: string | null;
    isSystem: boolean;
  };
}
```
