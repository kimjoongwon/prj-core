# GroupInfoSection Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/group/GroupInfoSection/

## 역할

그룹 상세 화면에서 기본 정보(이름, 라벨, 유형, 생성일, 수정일)를 2열 그리드로 표시하는 섹션입니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
  ┌─────────────────────────────────────────────────────┐
  │  이름              │  라벨                          │
  │  TRUSTED           │  신뢰 그룹                     │
  ├─────────────────────────────────────────────────────┤
  │  유형              │  생성일                        │
  │  ROLE_GROUP        │  2026-01-01 09:00:00           │
  ├─────────────────────────────────────────────────────┤
  │  수정일             │                               │
  │  2026-02-15 14:30  │                               │
  └─────────────────────────────────────────────────────┘

  --- 라벨 없음 ---

  ┌─────────────────────────────────────────────────────┐
  │  이름              │  라벨                          │
  │  STANDARD          │  -                             │
  ├─────────────────────────────────────────────────────┤
  │  유형              │  생성일                        │
  │  ROLE_GROUP        │  2026-01-05 10:00:00           │
  ├─────────────────────────────────────────────────────┤
  │  수정일             │                               │
  │  2026-02-10 09:00  │                               │
  └─────────────────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 라벨 있음 | 라벨 셀에 텍스트 표시 |
| 라벨 없음 | 라벨 셀에 "-" 또는 빈 값 표시 |

## Props

```typescript
interface GroupInfoSectionProps {

interface GroupInfo {
  name: string;
  label?: string | null;
  type: string;
  createdAt: string;
  updatedAt: string;
}
```
