# TemplateContentViewer Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/TemplateContentViewer/

## 역할

상세 화면에서 템플릿 유형별 콘텐츠를 읽기 전용으로 표시합니다. EMAIL: 제목 + HtmlContentRenderer, SMS: 텍스트 + ByteCounter, PUSH: 제목/본문 + 글자 수 표시.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[EMAIL 유형]
┌──────────────────────────────────────────────────┐
│  제목                                             │
│  [인증코드] {{name}}님의 인증번호입니다            │
│  ─────────────────────────────────────────────── │
│  본문 (HTML 렌더링)                               │
│  ┌────────────────────────────────────────────┐  │
│  │                                            │  │
│  │  안녕하세요, {{name}}님!                   │  │
│  │                                            │  │
│  │  인증번호는 [123456] 입니다.               │  │
│  │  유효 시간: 5분                            │  │
│  │                                            │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘

[SMS 유형]
┌──────────────────────────────────────────────────┐
│  본문                                             │
│  ┌────────────────────────────────────────────┐  │
│  │  [인증코드] {{name}}님의 인증번호:          │  │
│  │  {{code}}                                  │  │
│  └────────────────────────────────────────────┘  │
│                              24 bytes             │
└──────────────────────────────────────────────────┘

[PUSH 유형]
┌──────────────────────────────────────────────────┐
│  제목                           12자              │
│  새로운 알림이 있습니다                            │
│  ─────────────────────────────────────────────── │
│  본문                           35자              │
│  {{name}}님, 확인이 필요한 항목이 있습니다.        │
└──────────────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| EMAIL | 제목 텍스트 + HTML 렌더링 영역 (읽기 전용) |
| SMS | 본문 텍스트 박스 (회색 배경) + 바이트 카운터 |
| PUSH | 제목/본문 텍스트 + 각 글자 수 표시 |

## Props

```typescript
interface TemplateContentViewerProps {
  type: "EMAIL" | "SMS" | "PUSH";
  subject: string | null;
  content: string;
}
```

## 하위 UI 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|
| HtmlContentRenderer | EMAIL HTML 렌더링 |
| ByteCounter | SMS 바이트 수 표시 |
