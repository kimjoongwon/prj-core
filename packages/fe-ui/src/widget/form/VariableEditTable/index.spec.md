# VariableEditTable Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/form/VariableEditTable/

## 역할

등록/수정 폼에서 템플릿 변수를 인라인으로 추가/수정/삭제하는 테이블입니다. 변수명 유효성 검증과 본문 내 사용 여부 확인 기능을 제공합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
┌────────────────────────────────────────────────────────────────────┐
│  변수 목록                                          [+ 변수 추가]   │
├──────────────┬──────────────┬────────────────┬──────────┬──────────┤
│  변수명      │  설명        │  기본값        │  필수    │          │
├──────────────┼──────────────┼────────────────┼──────────┼──────────┤
│ [name      ] │ [이름       ]│ [홍길동      ] │  ● (ON) │   [🗑]   │
├──────────────┼──────────────┼────────────────┼──────────┼──────────┤
│ [code      ] │ [인증코드   ]│ [           ] │  ○ (OFF)│   [🗑]   │
├──────────────┼──────────────┼────────────────┼──────────┼──────────┤
│ [expiry ⚠ ] │ [만료시간   ]│ [5분         ] │  ● (ON) │   [🗑]   │
│ ⚠ 본문에서 사용 중인 변수는 삭제 시 오류가 발생할 수 있습니다.    │
└──────────────┴──────────────┴────────────────┴──────────┴──────────┘

[오류 상태 - 변수명 중복]
├──────────────┤
│ [name ❌   ] │
│ 이미 사용 중인 변수명입니다.                                       │

[빈 상태]
┌────────────────────────────────────────────────────────────────────┐
│  변수가 없습니다.                               [+ 변수 추가]       │
└────────────────────────────────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 4개 컬럼 인라인 편집 테이블 + 추가/삭제 버튼 |
| 오류 (errors 있음) | 해당 셀 빨간 테두리 + 아래 오류 메시지 |
| 본문 사용 중 경고 | 변수명 옆 경고 아이콘 + 툴팁 |
| 빈 상태 | 빈 메시지 + 추가 버튼만 표시 |

## Props

```typescript
interface VariableEditTableProps {
  variables: VariableEditItem[];
  onChange: (variables: VariableEditItem[]) => void;
  contentText?: string;
  errors?: Record<number, Record<string, string>>;
}

interface VariableEditItem {
  id?: string;
  name: string;
  description: string;
  defaultValue: string;
  isRequired: boolean;
}
```
