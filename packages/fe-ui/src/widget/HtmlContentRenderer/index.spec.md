# HtmlContentRenderer Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/widget/HtmlContentRenderer/

## 역할

EMAIL 유형의 HTML 본문을 안전하게 렌더링합니다. iframe sandbox로 격리하고, script 태그를 사전 제거하여 XSS를 방지합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
기본 렌더링 (maxHeight: 400)
┌──────────────────────────────────────────┐
│ ┌────────────────────────────────────┐   │
│ │  [iframe sandbox]                  │   │
│ │                                    │   │
│ │   <HTML 이메일 본문 렌더링>         │   │
│ │                                    │   │
│ │   제목: 안녕하세요                  │   │
│ │   본문 내용이 여기에 표시됩니다.     │   │
│ │   이미지, 링크 등이 포함될 수 있음  │   │
│ │                                    │   │
│ └────────────────────────────────────┘   │
│                              400px 높이   │
└──────────────────────────────────────────┘

긴 콘텐츠 (스크롤 발생)
┌──────────────────────────────────────────┐
│ ┌────────────────────────────────────┐   │
│ │  [iframe sandbox]                  │   │
│ │   ...콘텐츠...                     │   │
│ │   ...콘텐츠...                     │ ▲ │
│ │   ...콘텐츠...                     │ █ │  ← iframe 내부 스크롤
│ │   ...콘텐츠...                     │ ▼ │
│ └────────────────────────────────────┘   │
│                              400px 고정   │
└──────────────────────────────────────────┘

빈 HTML
┌──────────────────────────────────────────┐
│ ┌────────────────────────────────────┐   │
│ │  [iframe sandbox]                  │   │
│ │                                    │   │
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | iframe 내 HTML 안전 렌더링 (maxHeight 400px) |
| 커스텀 높이 | maxHeight prop으로 높이 조절 |
| 긴 콘텐츠 | iframe 내부 스크롤 처리 |

## Props

```typescript
interface HtmlContentRendererProps {
  html: string;
  maxHeight?: number;  // 기본값: 400
}
```
