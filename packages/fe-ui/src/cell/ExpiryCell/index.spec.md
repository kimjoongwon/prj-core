# ExpiryCell 기획서

> 생성일: 2026-02-18
> 타입: ui (cell)
> 위치: packages/fe-ui/src/cell/ExpiryCell/

## 역할

만료 시간과 남은 시간을 함께 표시하는 Cell 컴포넌트. 상단에 날짜/시간, 하단에 상대 시간(남은 시간 또는 "만료됨")을 표시한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
테이블 컬럼 내 표시 형태:

┌────────────────┬───────────────────────┬──────────┐
│ 토큰명         │ 만료 시간             │ 상태     │
├────────────────┼───────────────────────┼──────────┤
│ access-token-1 │ 2024-03-15 10:30      │ 활성     │
│                │ 3d 5h 남음  ← 초록색  │          │
├────────────────┼───────────────────────┼──────────┤
│ access-token-2 │ 2024-01-10 08:00      │ 만료     │
│                │ 만료됨      ← 빨간색  │          │
├────────────────┼───────────────────────┼──────────┤
│ access-token-3 │ 2024-02-28 23:59      │ 활성     │
│                │ 2h 15m 남음 ← 초록색  │          │
├────────────────┼───────────────────────┼──────────┤
│ access-token-4 │      -                │ 없음     │
└────────────────┴───────────────────────┴──────────┘

셀 내부 구조 (2줄 표시):

  ┌────────────────────────┐
  │ 2024-03-15 10:30       │  ← 상단: formatDateTime() 결과 (기본 텍스트색)
  │ 3d 5h 남음             │  ← 하단: 상대 시간 (text-success 초록색)
  └────────────────────────┘

  ┌────────────────────────┐
  │ 2024-01-10 08:00       │  ← 상단: formatDateTime() 결과
  │ 만료됨                 │  ← 하단: 만료 텍스트 (text-danger 빨간색)
  └────────────────────────┘

  ┌────────────────────────┐
  │ -                      │  ← null/undefined: 단일 "-" 표시
  └────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 미래 (일 단위) | `2024-03-15 10:30` / `3d 5h 남음` (초록색) |
| 미래 (시 단위) | `2024-03-15 10:30` / `2h 15m 남음` (초록색) |
| 미래 (분 단위) | `2024-03-15 10:30` / `45m 남음` (초록색) |
| 과거 (만료) | `2024-01-10 08:00` / `만료됨` (빨간색) |
| 없음 | `-` |

## Props

```typescript
interface ExpiryCellProps {

  expiresAt: string | Date | null | undefined;
}
```

## 표시 규칙

| 조건 | 상단 표시 | 하단 표시 | 하단 색상 |
|---|---|---|---|
| 미래 시간 (일 단위) | formatDateTime 결과 | `Xd Yh 남음` | text-success |
| 미래 시간 (시 단위) | formatDateTime 결과 | `Xh Ym 남음` | text-success |
| 미래 시간 (분 단위) | formatDateTime 결과 | `Xm 남음` | text-success |
| 과거 시간 | formatDateTime 결과 | 만료됨 | text-danger |
| `null` / `undefined` | - | (없음) | text-default-400 |
