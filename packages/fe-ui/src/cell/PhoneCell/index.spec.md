# PhoneCell 기획서

> 생성일: 2026-02-18
> 타입: ui (cell)
> 위치: packages/fe-ui/src/cell/PhoneCell/

## 역할

전화번호를 한국식 포맷(하이픈 포함)으로 변환하여 표시하는 Cell 컴포넌트.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
테이블 컬럼 내 표시:

┌────────────────────┐
│ 전화번호            │
├────────────────────┤
│ 010-1234-5678      │  ← 11자리 휴대폰
├────────────────────┤
│ 02-1234-5678       │  ← 10자리 서울 지역번호
├────────────────────┤
│ 031-123-4567       │  ← 10자리 경기 지역번호
├────────────────────┤
│ -                  │  ← null/undefined (text-default-400, 회색)
└────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 휴대폰 (11자리) | `010-1234-5678` |
| 서울 지역번호 (10자리) | `02-1234-5678` |
| 지방 지역번호 (10자리) | `031-123-4567` |
| 이미 포맷팅됨 | `010-1234-5678` (그대로 표시) |
| null / undefined | `-` (text-default-400, 흐린 회색) |

## Props

```typescript
interface PhoneCellProps {
  /** 전화번호 */
  value?: string | null;
}
```

## 표시 규칙

| 입력 | 표시 | 설명 |
|---|---|---|
| `01012345678` | 010-1234-5678 | 11자리 휴대폰 |
| `0212345678` | 02-1234-5678 | 10자리 서울 |
| `0311234567` | 031-123-4567 | 10자리 지역 |
| `010-1234-5678` | 010-1234-5678 | 이미 포맷팅됨 (그대로) |
| `null` / `undefined` / `""` | - | text-default-400 |
