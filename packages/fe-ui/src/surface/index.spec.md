## 역할

`@cocrepo/ui`의 Surface 계층 공개 진입점을 제공합니다.
Surface 계층은 layout이 정한 위치 위에 어떤 시각적 표면을 적용할지 결정합니다.

## 공개 항목

| 항목 | 설명 |
|------|------|
| `Surface` | 기본 엘리베이션/패딩 표면 |
| `PageSurface` | 페이지 단위 raised 표면 |
| `SectionSurface` | 섹션 단위 elevated 표면 |
