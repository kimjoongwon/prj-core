# LinkCell 기획서

> 생성일: 2026-02-18
> 타입: ui (cell)
> 위치: packages/fe-ui/src/components/ui/data-display/cells/LinkCell/

## 역할

클릭 가능한 링크로 값을 표시하는 Cell 컴포넌트. HeroUI Link의 모든 props를 지원한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
테이블 컬럼 내 표시 형태:

┌───────────┬────────────────────────────┬──────────┐
│ ID        │ 이름 (링크)                │ 상태     │
├───────────┼────────────────────────────┼──────────┤
│ uuid-001  │ 홍길동            [↗]      │ 활성     │
│           │ (밑줄, 파란색 링크)         │          │
├───────────┼────────────────────────────┼──────────┤
│ uuid-002  │ 외부 사이트       [↗]      │ 활성     │
│           │ (isExternal=true, 새 탭)   │          │
├───────────┼────────────────────────────┼──────────┤
│ uuid-003  │ 클릭 액션 항목             │ 비활성   │
│           │ (onPress 핸들러)           │          │
└───────────┴────────────────────────────┴──────────┘

셀 내부 구조:

  홍길동         ← HeroUI Link (밑줄, primary색)
  외부 사이트 ↗  ← HeroUI Link (isExternal=true, 외부 링크 아이콘)
  클릭 액션 항목 ← HeroUI Link (onPress 핸들러)
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 내부 링크 (`href` 제공) | `홍길동` - 파란색 밑줄 링크, 클릭 시 이동 |
| 외부 링크 (`isExternal=true`) | `외부 사이트 ↗` - 외부 링크 아이콘 포함, 새 탭 열기 |
| 액션 링크 (`onPress` 제공) | `클릭 액션 항목` - 파란색 밑줄 링크, 클릭 시 핸들러 실행 |

## Props

```typescript
interface LinkCellViewProps extends LinkProps {
  /** 링크 텍스트 */
  value: string;
}
```

## 표시 규칙

| 조건 | 동작 |
|---|---|
| `href` 제공 | 해당 경로로 이동하는 링크 렌더링 |
| `isExternal` | 외부 링크로 동작 |
| `onPress` | 클릭 핸들러 실행 |

## HeroUI 매핑

- `Link` 컴포넌트 - `value`를 children으로 전달하고 나머지 props를 spread
