## 역할

업로드 큐의 개별 파일 항목을 표시하는 컴포넌트입니다. 파일명, 크기, 진행률, 상태를 보여주며 일시정지/재개/취소 버튼을 제공합니다.

## Props

```typescript
interface UploadQueueItemProps {
  id: string;                                // 항목 고유 ID
  file: File;                                // 파일 객체
  fileName: string;                          // 파일명
  fileSize: number;                          // 파일 크기 (bytes)
  progress?: number;                         // 진행률 (0-100)
  status: UploadStatus;                      // 업로드 상태
  errorMessage?: string;                     // 에러 메시지
  onPause?: () => void;                      // 일시정지 핸들러
  onResume?: () => void;                     // 재개 핸들러
  onCancel?: () => void;                     // 취소 핸들러
  onRetry?: () => void;                      // 재시도 핸들러
  showThumbnail?: boolean;                   // 썸네일 표시 여부
  className?: string;                        // 추가 클래스
}

type UploadStatus = 'pending' | 'uploading' | 'paused' | 'completed' | 'failed';
```

## 상태

| 상태 | 스타일 |
|------|--------|
| `pending` | opacity-70, 진행률 바 회색 |
| `uploading` | 진행률 바 primary 색상 |
| `paused` | 진행률 바 warning 색상 |
| `completed` | 진행률 바 success 색상, 체크 아이콘 |
| `failed` | 배경 danger/10, 에러 메시지 표시 |
