# Textarea Input 기획서

> 생성일: 2026-02-18
> 타입: input
> 위치: packages/fe-ui/src/components/inputs/Textarea/

## 역할

MobX state와 연동하는 여러 줄 텍스트 입력 컴포넌트. `useFormField` 훅을 통해 문자열의 양방향 바인딩을 제공한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
기본 상태 (빈 입력, minRows=3)
┌──────────────────────────────┐
│ 설명                          │  ← label
│ ┌────────────────────────┐   │
│ │ 내용을 입력하세요        │   │  ← placeholder (회색)
│ │                        │   │
│ │                        │   │  ← 최소 3행 높이 유지
│ └────────────────────────┘   │
└──────────────────────────────┘

입력 중 상태 (포커스)
┌──────────────────────────────┐
│ 설명                          │
│ ┌────────────────────────┐   │  ← 파란 테두리 (focus ring)
│ │ 첫 번째 줄              │   │
│ │ 두 번째 줄▊             │   │  ← 커서
│ │                        │   │
│ └────────────────────────┘   │
└──────────────────────────────┘

값 입력 완료 (자동 높이 확장)
┌──────────────────────────────┐
│ 설명                          │
│ ┌────────────────────────┐   │
│ │ 첫 번째 단락 내용입니다. │   │
│ │ 두 번째 단락입니다.      │   │
│ │ 세 번째 줄              │   │
│ │ 네 번째 줄              │   │  ← 내용에 따라 자동 확장
│ └────────────────────────┘   │
└──────────────────────────────┘

오류 상태
┌──────────────────────────────┐
│ 설명                          │
│ ┌────────────────────────┐   │  ← 빨간 테두리
│ │                        │   │
│ │                        │   │
│ └────────────────────────┘   │
│ ⚠ 설명을 입력해 주세요        │
└──────────────────────────────┘

글자 수 제한 표시 (maxLength)
┌──────────────────────────────┐
│ 한 줄 소개                    │
│ ┌────────────────────────┐   │
│ │ 안녕하세요. 저는 ...    │   │
│ │                        │   │
│ └────────────────────────┘   │
│                      45/100  │  ← 우측 하단 글자 수 카운터
└──────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 라벨 + 여러 줄 입력 필드 (minRows 적용) |
| 포커스 | 파란 테두리 (focus ring) |
| 자동 확장 | 내용 입력 시 높이 자동 증가 |
| 오류 | 빨간 테두리 + 하단 오류 메시지 |
| 글자 수 | 우측 하단 `현재/최대` 카운터 표시 |
| 비활성화 | 흐린 배경, 입력 불가 |

## Props

```typescript
interface TextareaProps<T> extends MobxProps<T>,
  Omit<BaseTextareaProps, "value" | "onChange"> {}
```

- `state`: MobX observable 객체
- `path`: state 내 바인딩 경로
- 나머지 BaseTextareaProps 전달 (label, placeholder, minRows 등)

## 상태

| 상태 | 설명 |
|------|------|
| 초기값 | `tools.get(state, path, "")` (string) |
| 변경 시 | `formField.setValue(value)`로 state 업데이트 |

## MobX 연동

- `observer`로 래핑
- `useFormField` 훅으로 양방향 바인딩
