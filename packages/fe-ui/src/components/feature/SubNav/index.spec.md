# SubNav Feature 기획서

> 생성일: 2026-02-18
> 타입: feature
> 위치: packages/fe-ui/src/components/feature/SubNav/

## 역할

Header의 bottom 영역에 표시되는 서브 네비게이션 Feature 컴포넌트입니다.
NavigationStore에서 현재 선택된 1depth 아이템의 2depth 하위 아이템을 가져와 수평 버튼으로 렌더링합니다.
하위 아이템이 없으면 렌더링하지 않습니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 상태별 UI를 ASCII로 표현합니다.

```
[하위 메뉴가 있는 경우 - Header 하단 영역]

┌─────────────────────────────────────────────────────────────────┐
│  Header 상단 (로고, 스페이스 선택, 사용자 메뉴 등)              │
├─────────────────────────────────────────────────────────────────┤
│  SubNav 영역 (border-top)                                        │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │  회원 목록 │  │  등급 관리 │  │  포인트  │  │  출석 관리 │        │
│  │ (활성상태) │  │          │  │   내역   │  │          │        │
│  └──────────┘  └──────────┘  └──────────┘  └──────────┘        │
│   ↑ 선택된 항목: primary 색상, 하단 라인 강조                   │
└─────────────────────────────────────────────────────────────────┘

[하위 메뉴가 없는 경우 - null 반환, 렌더링 안 함]

┌─────────────────────────────────────────────────────────────────┐
│  Header 상단 (로고, 스페이스 선택, 사용자 메뉴 등)              │
│  (SubNav 없음 - 1depth 아이템에 하위 메뉴가 없을 때)            │
└─────────────────────────────────────────────────────────────────┘
```

### 상태별 UI 변화

| 상태 | 설명 | 시각적 변화 |
|------|------|-------------|
| 기본 | 비활성 2depth 버튼 | 기본 텍스트 색상 |
| 선택됨 | 활성 2depth 버튼 | primary 색상 + 하단 강조 선 |
| 없음 | 하위 아이템 0개 | null 반환 (컴포넌트 미렌더링) |
| 로딩 | 스켈레톤 또는 스피너 | SSR 이후 hydration 완료 전 |

## 의존성

| 타입 | 대상 | 용도 |
|------|------|------|
| Store | `@cocrepo/store` > `useNavigationStore` | 하위 네비게이션 아이템 조회 및 선택 |
| UI Library | `@heroui/react` > `cn` | 조건부 클래스 적용 |
| Util | `iconUtils` > `renderLucideIcon` | Lucide 아이콘 렌더링 |

| Store | 속성/메서드 | 사용 방식 |
