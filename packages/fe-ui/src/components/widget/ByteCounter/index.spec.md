# ByteCounter Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/components/widget/ByteCounter/

## 역할

SMS 본문의 바이트 수와 장수를 실시간으로 표시합니다. 한글 2바이트, 영문/숫자 1바이트 기준으로 계산합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
정상 범위 (1장)
┌──────────────────────────┐
│  45 bytes / 90  │  1장   │
└──────────────────────────┘

초과 (2장)
┌──────────────────────────┐
│  102 bytes / 90 │  2장   │  ← 바이트 수 강조(경고색)
└──────────────────────────┘

빈 입력
┌──────────────────────────┐
│   0 bytes / 90  │  1장   │
└──────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 정상 | `45 bytes / 90 · 1장` (기본 텍스트 색상) |
| 초과 | `102 bytes / 90 · 2장` (경고 색상 강조) |
| 빈 입력 | `0 bytes / 90 · 1장` |

## Props

```typescript
interface ByteCounterProps {
  text: string;
  bytesPerMessage?: number;  // 기본값: 90
```
