# LoginForm Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/components/widget/form/LoginForm/

## 역할

이메일과 비밀번호 입력 필드를 제공하는 간단한 로그인 폼입니다. state 객체를 직접 받아 Input 컴포넌트의 path 바인딩을 사용합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
  ┌────────────────────────────────────────┐
  │ 이메일                                  │
  │ ┌──────────────────────────────────┐   │
  │ │ user@example.com                 │   │
  │ └──────────────────────────────────┘   │
  │                                        │
  │ 비밀번호                                │
  │ ┌──────────────────────────────────┐   │
  │ │ ••••••••                         │   │
  │ └──────────────────────────────────┘   │
  └────────────────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 이메일 + 비밀번호 Input 세로 배치 |
| 입력 중 | 각 Input에 포커스 링 표시 |
| 에러 | 외부(상위 컴포넌트)에서 처리 (이 컴포넌트는 순수 입력만 담당) |

## Props

```typescript
interface LoginFormProps {
  state: {
    email: string;
    password: string;
  };
}
```

## 하위 UI 컴포넌트

| 컴포넌트 | 역할 |
|----------|------|

| VStack | 레이아웃 |
