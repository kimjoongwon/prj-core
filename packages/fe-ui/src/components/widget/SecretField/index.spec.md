# SecretField Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/components/widget/SecretField/

## 역할

비밀 값(Client Secret 등)을 마스킹/표시 토글/클립보드 복사할 수 있는 위젯입니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[마스킹 상태 (기본, isVisible=false)]
┌─────────────────────────────────────────────┬──────┬──────┐
│  ••••••••••••••••                            │  👁  │  📋  │
└─────────────────────────────────────────────┴──────┴──────┘
                                               [보기] [복사]

[표시 상태 (isVisible=true)]
┌─────────────────────────────────────────────┬──────┬──────┐
│  sk-abc123XYZ456def789...                   │  🙈  │  📋  │
└─────────────────────────────────────────────┴──────┴──────┘
                                               [숨기기] [복사]

[복사 완료 상태]
┌─────────────────────────────────────────────┬──────┬──────┐
│  ••••••••••••••••                            │  👁  │  ✓   │
└─────────────────────────────────────────────┴──────┴──────┘
                                                      [복사됨]

[값 없음 상태 (value=null)]
┌─────────────────────────────────────────────┬──────┬──────┐
│  (없음)                                      │  👁  │  📋  │
└─────────────────────────────────────────────┴──────┴──────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 마스킹 (기본) | 불릿 문자로 값 숨김 + 눈 아이콘(보기) + 복사 버튼 |
| 표시 | 실제 값 노출 + 눈 감김 아이콘(숨기기) + 복사 버튼 |
| 값 없음 | "(없음)" 텍스트, 버튼 비활성화 |

## Props

```typescript
interface SecretFieldProps {
  value: string | null | undefined;
  maskChar?: string;     // 기본값: "•" (bullet)
  maskLength?: number;   // 기본값: 16
}
```
