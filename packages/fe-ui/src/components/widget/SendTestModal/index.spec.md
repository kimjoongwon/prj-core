# SendTestModal Widget 기획서

> 생성일: 2026-02-18
> 타입: widget
> 위치: packages/fe-ui/src/components/widget/SendTestModal/

## 역할

메시지 템플릿 상세 화면에서 테스트 발송을 수행하는 모달입니다. 유형(EMAIL/SMS/PUSH)에 따라 적절한 수신자 입력 필드를 표시하고, 변수 입력과 발송 결과를 렌더링합니다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[EMAIL 유형 - 입력 상태]
┌────────────────────────────────────────────────────┐
│  테스트 발송                                    [x] │
├────────────────────────────────────────────────────┤
│  수신자 이메일                                      │
│  ┌──────────────────────────────────────────────┐  │
│  │  test@example.com                            │  │
│  └──────────────────────────────────────────────┘  │
│                                                      │
│  변수 입력                                           │
│  ┌─────────────────┐                                │
│  │ 이름 *          │                                │
│  │ [홍길동        ] │                                │
│  └─────────────────┘                                │
│  ┌─────────────────┐                                │
│  │ 코드            │                                │
│  │ [123456        ] │                                │
│  └─────────────────┘                                │
├────────────────────────────────────────────────────┤
│                      [취소]  [발송]                  │

│  │  010-1234-5678                               │  │

┌────────────────────────────────────────────────────┐
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| EMAIL | 이메일 주소 입력 + 변수 폼 + 발송 버튼 |
| SMS | 전화번호 입력 + 변수 폼 + 발송 버튼 |
| PUSH | 디바이스 토큰/주소 입력 + 변수 폼 + 발송 버튼 |
| 발송 중 (status=loading) | 버튼 로딩 스피너 표시 |
| 성공 (status=success) | 초록 체크 아이콘 + 성공 메시지 |
| 실패 (status=error) | 빨간 경고 아이콘 + 오류 메시지 |

## Props

```typescript
interface SendTestModalProps {
  isOpen: boolean;
  onClose: () => void;
  templateId: string;
  type: "EMAIL" | "SMS" | "PUSH";
  variables: TemplateVariable[];
  onSendTest: (templateId: string, recipient: string, variables: Record<string, string>) => Promise<SendTestResult>;
}
```

## 하위 UI 컴포넌트

| 컴포넌트 | 역할 |

로컬: recipient, variableValues, result(SendTestResult), status("idle"/"loading"/"success"/"error")
