# Input 기획서

> 생성일: 2026-02-18
> 타입: input
> 위치: packages/fe-ui/src/control/Input/

## 역할

MobX state와 연동하는 텍스트/숫자 입력 컴포넌트. `useFormField` 훅을 통해 양방향 바인딩을 제공한다. onChange와 onBlur 모두에서 state를 업데이트한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
기본 상태 (빈 입력)
┌──────────────────────────────┐
│ 이름                          │  ← label
│ ┌────────────────────────┐   │
│ │ 이름을 입력하세요        │   │  ← placeholder (회색)
│ └────────────────────────┘   │
└──────────────────────────────┘

입력 중 상태 (포커스)
┌──────────────────────────────┐
│ 이름                          │
│ ┌────────────────────────┐   │  ← 파란 테두리 (focus ring)
│ │ 홍길동▊                 │   │  ← 커서 표시
│ └────────────────────────┘   │
└──────────────────────────────┘

값 입력 완료 상태
┌──────────────────────────────┐
│ 이름                          │
│ ┌────────────────────────┐   │
│ │ 홍길동                  │   │
│ └────────────────────────┘   │
└──────────────────────────────┘

오류 상태
┌──────────────────────────────┐
│ 이름                          │
│ ┌────────────────────────┐   │  ← 빨간 테두리
│ │                        │   │
│ └────────────────────────┘   │
│ ⚠ 이름을 입력해 주세요        │  ← 오류 메시지
└──────────────────────────────┘

비활성화 상태
┌──────────────────────────────┐
│ 이름                          │
│ ┌────────────────────────┐   │
│ │ 홍길동 (비활성화)        │   │  ← 흐린 텍스트, 배경 어둡게
│ └────────────────────────┘   │
└──────────────────────────────┘

아이콘 포함 (startContent / endContent)
┌──────────────────────────────┐
│ 이메일                        │
│ ┌─[✉]───────────────────┐   │
│ │ example@email.com      │   │
│ └────────────────────────┘   │
└──────────────────────────────┘

숫자 타입 (type="number")
┌──────────────────────────────┐
│ 수량                          │
│ ┌──────────────────────[▲]┐  │
│ │ 10                    [▼]│  │
│ └──────────────────────────┘  │
└──────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 라벨 + 테두리 입력 필드 |
| 포커스 | 파란 테두리 (focus ring) |
| 오류 | 빨간 테두리 + 하단 오류 메시지 |
| 비활성화 | 흐린 배경, 입력 불가 |
| 아이콘 | 좌측/우측 아이콘 포함 |
| 숫자 | 스피너(▲▼) 내장 |

## Props

```typescript
interface InputProps<T> extends MobxProps<T>,
  Omit<BaseInputProps, "value" | "onChange" | "onBlur"> {}
```

- `state`: MobX observable 객체
- `path`: state 내 바인딩 경로
- 나머지 BaseInputProps 전달 (label, placeholder, type 등)

## 상태

| 상태 | 설명 |
|------|------|
| 초기값 | `tools.get(state, path)` (string 또는 number, 기본 "") |
| onChange | `formField.setValue(value)`로 state 업데이트 |
| onBlur | `formField.setValue(value)`로 state 업데이트 |

## MobX 연동

- `observer`로 래핑
- `useFormField` 훅으로 양방향 바인딩
