# CharacterCounter Input 기획서

> 생성일: 2026-02-18
> 타입: input (보조)
> 위치: packages/fe-ui/src/control/CharacterCounter/

## 역할

텍스트 입력의 현재 글자 수와 최대 글자 수를 "현재 / 최대" 형태로 표시하는 보조 컴포넌트. 80% 이상이면 경고색, 초과하면 위험색으로 표시한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
[일반 상태 - 0% ~ 79%]
                                    20 / 100

[경고 상태 - 80% 이상]
                                    83 / 100   (노란색)

[초과 상태 - 100% 초과]
                                   105 / 100   (빨간색)

[텍스트 입력 영역과 함께 사용 예시]
┌─────────────────────────────────────┐
│ 내용을 입력하세요...                │
│                                     │
│                                     │
│                                     │
└─────────────────────────────────────┘
                                20 / 100

┌─────────────────────────────────────┐
│ 경고 임계값에 가까워지는 내용을 입력│
│ 하면 글자 수가 노란색으로 표시됩니다│
│                                     │
└─────────────────────────────────────┘
                                83 / 100   (🟡 노란색)

┌─────────────────────────────────────┐
│ 최대 글자 수를 초과하면 빨간색으로  │
│ 표시되어 사용자에게 경고를 줍니다.  │
│ 초과분도 계속 표시됩니다.          │
└─────────────────────────────────────┘
                               105 / 100   (🔴 빨간색)
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 (0~79%) | 회색 텍스트 `20 / 100` |
| 경고 (80% 이상) | 노란색 텍스트 `83 / 100` |
| 초과 (100% 초과) | 빨간색 텍스트 `105 / 100` |
| showWarning=false | 경고 색상 미적용, 초과 시에만 빨간색 |

## Props

```typescript
interface CharacterCounterProps {
  /** 현재 글자 수 */
  current: number;
  /** 최대 글자 수 */
  max: number;
  /** 경고 표시 여부 @default true */
  showWarning?: boolean;
  /** 추가 CSS 클래스 */
  className?: string;
}
```

## 표시 규칙

| 조건 | 색상 |
|------|------|
| `current > max` | text-danger |
| `current >= max * 0.8` (showWarning=true) | text-warning |
| 그 외 | text-default-500 |
