# TimeInput 기획서

> 생성일: 2026-02-18
> 타입: input
> 위치: packages/fe-ui/src/input/TimeInput/

## 역할

MobX state와 연동하는 시간 입력 컴포넌트. `useFormField` 훅을 통해 시간 문자열의 양방향 바인딩을 제공한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
기본 상태 (빈 값)
┌──────────────────────────────┐
│ 시작 시간                     │  ← label
│ ┌────────────────────────┐   │
│ │  --  :  --             │   │  ← 시/분 플레이스홀더
│ └────────────────────────┘   │
└──────────────────────────────┘

값 입력 상태
┌──────────────────────────────┐
│ 시작 시간                     │
│ ┌────────────────────────┐   │
│ │  09  :  30             │   │  ← 시:분 입력됨
│ └────────────────────────┘   │
└──────────────────────────────┘

포커스 상태 (시 섹션 활성)
┌──────────────────────────────┐
│ 시작 시간                     │
│ ┌────────────────────────┐   │  ← 파란 테두리
│ │ [09] :  30             │   │  ← 시 섹션 하이라이트
│ └────────────────────────┘   │
└──────────────────────────────┘

12시간제 (AM/PM 포함)
┌──────────────────────────────┐
│ 미팅 시간                     │
│ ┌────────────────────────┐   │
│ │  09  :  30  AM         │   │  ← AM/PM 토글
│ └────────────────────────┘   │
└──────────────────────────────┘

오류 상태
┌──────────────────────────────┐
│ 시작 시간                     │
│ ┌────────────────────────┐   │  ← 빨간 테두리
│ │  --  :  --             │   │
│ └────────────────────────┘   │
│ ⚠ 시간을 입력해 주세요        │
└──────────────────────────────┘

비활성화 상태
┌──────────────────────────────┐
│ 시작 시간                     │
│ ┌────────────────────────┐   │  ← 흐린 배경
│ │  09  :  30  (비활성)    │   │
│ └────────────────────────┘   │
└──────────────────────────────┘
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| 기본 | 라벨 + 시:분 세그먼트 입력 필드 |
| 포커스 | 파란 테두리, 활성 세그먼트(시/분) 하이라이트 |
| 12시간제 | 시:분 + AM/PM 토글 추가 |
| 오류 | 빨간 테두리 + 하단 오류 메시지 |
| 비활성화 | 흐린 배경, 입력 불가 |

## Props

```typescript
interface TimeInputProps<T> extends MobxProps<T>,
  Omit<BaseTimeInputProps<T>, "value" | "onChange"> {}
```

- `state`: MobX observable 객체
- `path`: state 내 바인딩 경로
- 나머지 BaseTimeInputProps 전달

## 상태

| 상태 | 설명 |
|------|------|
| 초기값 | `tools.get(state, path)` (string 또는 "") |
| 변경 시 | `formField.setValue(value)`로 state 업데이트 |

## MobX 연동

- `observer`로 래핑
- `useFormField` 훅으로 양방향 바인딩
