# Tabs Input 기획서

> 생성일: 2026-02-18
> 타입: input
> 위치: packages/fe-ui/src/input/Tabs/

## 역할

MobX state와 연동하는 탭 선택 컴포넌트. `useFormField` 훅을 통해 선택된 탭 키의 양방향 바인딩을 제공한다.

## 디자인 목업

> 컴포넌트의 시각적 구조와 변형(variant)별 모습을 ASCII로 표현합니다.

```
기본 상태 (solid variant, 두 번째 탭 선택)
┌──────────────────────────────────────┐
│ ┌──────┬──────────┬──────┬────────┐  │
│ │ 전체 │░░진행중░░│ 완료 │ 취소됨 │  │  ← 선택된 탭 배경색 강조
│ └──────┴──────────┴──────┴────────┘  │
│                                      │
│  [탭 컨텐츠 영역]                     │
└──────────────────────────────────────┘

underlined variant
┌──────────────────────────────────────┐
│  전체   진행중   완료   취소됨         │
│         ─────                         │  ← 선택된 탭 아래 파란 밑줄
│                                      │
│  [탭 컨텐츠 영역]                     │
└──────────────────────────────────────┘

bordered variant
┌──────────────────────────────────────┐
│ ┌──────┬──────────┬──────┬────────┐  │
│ │      │  진행중  │      │        │  │  ← 선택된 탭 테두리 강조
│ └──────┴──────────┴──────┴────────┘  │
└──────────────────────────────────────┘

아이콘 포함 탭
┌──────────────────────────────────────┐
│ ┌────────┬─────────┬──────────────┐  │
│ │ 📋 목록 │ 📊 통계 │ ⚙️ 설정      │  │
│ └────────┴─────────┴──────────────┘  │
└──────────────────────────────────────┘

크기 변형 (size="sm" / "md" / "lg")
[ 작게 | 선택됨 | 다른탭 ]   sm
[  작게  |  선택됨  |  다른탭  ]   md (기본)
[   작게   |   선택됨   |   다른탭   ]   lg
```

### 변형별 외형

| 변형 | 미리보기 |
|------|---------|
| solid (기본) | 선택된 탭 배경색(흰색/진한색) 강조 |
| underlined | 선택된 탭 하단 밑줄 표시 |
| bordered | 선택된 탭 테두리 강조 |
| light | 선택된 탭 배경 없이 텍스트 색상만 변경 |
| 아이콘 포함 | 아이콘 + 텍스트 |

## Props

```typescript
interface TabsProps<T> extends MobxProps<T>,
  Omit<BaseTabsProps, "selectedKey" | "onSelectionChange"> {}
```

- `state`: MobX observable 객체
- `path`: state 내 바인딩 경로
- `options`: 탭 목록 (BaseTabsProps에서 정의)

## 상태

| 상태 | 설명 |
|------|------|
| 초기값 | `tools.get(state, path)` |
| 변경 시 | `formField.setValue(key)`로 state 업데이트 |

## MobX 연동

- `observer`로 래핑
- `useFormField` 훅으로 양방향 바인딩
- selectedKey는 `String()`으로 변환하여 전달
