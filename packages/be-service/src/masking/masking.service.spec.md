# Masking Service 기획서

> 생성일: 2026-02-19
> 수정일: 2026-02-19
> 타입: service
> 위치: packages/be-service/src/masking.service.ts

## 역할

Action.config의 마스킹 설정을 실제 데이터에 적용하는 서비스입니다.
개인정보 보호를 위한 다양한 마스킹 프리셋과 커스텀 패턴을 지원합니다.
원본 객체를 수정하지 않고 새로운 객체/배열을 반환합니다.

## 의존성

| 의존 서비스/리포지토리 | 역할 |
|-----------------------|------|
| - | 외부 의존성 없음 (순수 서비스) |

## 메서드

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|----------|------|------|
| `applyMasking` | `value: string, config: ActionConfig` | `string` | Action config를 사용해 값 마스킹 |
| `maskFields` | `data: T, fieldsToMask: Map<string, ActionConfig>` | `T` | 객체의 특정 필드들을 마스킹 |
| `maskFieldsArray` | `dataArray: T[], fieldsToMask: Map<string, ActionConfig>` | `T[]` | 배열의 각 객체에 마스킹 적용 |

## 비즈니스 규칙

### 마스킹 프리셋

| 프리셋 | 예시 입력 | 예시 출력 | 설명 |
|--------|----------|----------|------|
| `PRESET_EMAIL` | minsu.kim92@gmail.com | min***@gmail.com | 로컬파트 앞 3자만 표시 |
| `PRESET_PHONE` | 010-5678-9012 | 010-****-9012 | 가운데 번호 마스킹 |
| `PRESET_NAME` | 김민수 | 김*수 | 첫자/끝자 유지, 가운데 마스킹 |
| `PRESET_SSN` | 920315-1234567 | 920315-******* | 뒷자리 전체 마스킹 |
| `PRESET_CARD` | 1234-5678-9012-3456 | 1234-****-****-3456 | 가운데 8자리 마스킹 |
| `PRESET_ACCOUNT` | 110-123-456789 | 110-***-****** | 계좌번호 마스킹 |

### 커스텀 패턴

- `pattern`: 정규식 문자열
- `replacement`: 치환 문자열 ($1, $2 등 캡처 그룹 사용 가능)

### 적용 조건

- `config.type !== "masking"` 이면 원본 반환
- `null/undefined/빈 문자열`이면 빈 문자열 반환
- 문자열 타입만 마스킹 적용 (다른 타입은 그대로 반환)

## 에러 처리

| 에러 상황 | 처리 방식 |
|----------|-----------|
| 알 수 없는 프리셋 | 원본 반환, 경고 로그 |
| 정규식 패턴 오류 | 원본 반환, 에러 로그 |
| 마스킹 설정 불완전 | 원본 반환, 경고 로그 |
