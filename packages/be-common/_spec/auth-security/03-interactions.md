# L5-L6: 인터랙션, API

## L5: Interaction (인터랙션)

### 여정 2: 일상 로그인 - 실패 시나리오

| 시나리오 | 트리거 | 시스템 응답 | 사용자 다음 행동 |
|---------|--------|------------|-----------------|
| 비밀번호 오류 (1~4회) | 로그인 제출 | "이메일 또는 비밀번호가 올바르지 않습니다. (남은 시도: N/5)" | 다시 시도 or 비밀번호 찾기 |
| 5회 연속 실패 → 일시 잠금 | 로그인 제출 | Alert: "계정이 일시 잠겼습니다. 15분 후 다시 시도하세요." 로그인 폼 비활성화 | 기다리기 or 비밀번호 재설정 |
| 10회 연속 실패 → 영구 잠금 | 로그인 제출 | Alert: "계정이 잠겼습니다. 비밀번호를 재설정하거나 관리자에게 문의하세요." [비밀번호 재설정] [관리자 문의] | 비밀번호 재설정 or 관리자 문의 |
| 비활성 계정 | 로그인 제출 | "이메일 또는 비밀번호가 올바르지 않습니다." (계정 존재 여부 노출 방지) | 관리자 문의 |
| 잠금 시간 경과 | 15분 후 재시도 | 자동 잠금 해제, 정상 로그인 가능. failedLoginAttempts 리셋 | 정상 로그인 |

### 여정 3: 세션 만료

| 시나리오 | 트리거 | 시스템 응답 | 사용자 다음 행동 |
|---------|--------|------------|-----------------|
| Access Token 만료 | API 401 응답 | fetch 클라이언트(customFetch)가 자동으로 Refresh Token 갱신 시도. 성공 시 원래 요청 재시도 (사용자 인지 못함) | 없음 (투명) |
| Refresh Token 갱신 실패 | 갱신 API 실패 | 토스트: "세션이 만료되었습니다. 다시 로그인해주세요." → 2초 후 로그인 페이지 이동 | 재로그인 |
| 관리자에 의한 세션 강제 종료 | API 401 응답 + 갱신 실패 | 토스트: "관리자에 의해 세션이 종료되었습니다." → 로그인 페이지 이동 | 재로그인 |
| 여러 탭 동시 갱신 | 여러 API 동시 401 | isRefreshing 플래그로 갱신 1회만. 나머지 요청은 큐에 대기 후 일괄 재시도 | 없음 (투명) |

### 여정 4: 로그아웃

| 시나리오 | 트리거 | 시스템 응답 | 사용자 다음 행동 |
|---------|--------|------------|-----------------|
| 현재 기기 로그아웃 | 드롭다운 "로그아웃" | 로딩 표시 → IDP 토큰 무효화 → 쿠키/로컬스토리지 정리 → 로그인 페이지 | 로그인 or 브라우저 닫기 |
| 모든 기기 로그아웃 | "모든 다른 기기에서 로그아웃" | 확인 다이얼로그 → 모든 Grant 폐기 → "다른 기기에서 모두 로그아웃되었습니다" 토스트 | 계속 작업 |
| 로그아웃 API 실패 | 네트워크 오류 등 | 쿠키는 삭제하고 로그인 페이지로 이동 (best-effort) | 로그인 |

### 여정 5: 비밀번호 재설정

| 시나리오 | 트리거 | 시스템 응답 | 사용자 다음 행동 |
|---------|--------|------------|-----------------|
| 이메일 제출 (존재) | 폼 제출 | "입력하신 이메일로 재설정 링크를 발송했습니다" + 이메일 발송 | 이메일 확인 |
| 이메일 제출 (미존재) | 폼 제출 | 동일 메시지 (존재 여부 노출 방지). 이메일 미발송 | 이메일 확인 (못 받으면 관리자 문의) |
| 재설정 링크 클릭 (유효) | 이메일 링크 | 새 비밀번호 입력 폼 표시 | 새 비밀번호 입력 |
| 재설정 링크 클릭 (만료) | 이메일 링크 (30분 초과) | "링크가 만료되었습니다" + [다시 요청하기] 버튼 | 다시 요청 |
| 재설정 링크 클릭 (이미 사용) | 이메일 링크 (일회용) | "이미 사용된 링크입니다" + [다시 요청하기] | 다시 요청 |
| 새 비밀번호 입력 중 | 타이핑 | 비밀번호 정책 표시 실시간 업데이트 (각 규칙 ✅/❌) | 규칙 충족하도록 수정 |
| 이전 비밀번호와 동일 | 제출 | "최근 사용한 비밀번호는 다시 사용할 수 없습니다" | 다른 비밀번호 입력 |
| 재설정 완료 | 폼 제출 | "비밀번호가 변경되었습니다. 다시 로그인해주세요" → 전체 세션 무효화 → 로그인 페이지 | 새 비밀번호로 로그인 |

## L6: API 엔드포인트

### IDP Server API (신규/강화)

#### Phase 1: 로그인 강화

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| POST | `/api/interaction/:uid/login` | 로그인 **(강화)** | 없음 | `{email, password, remember}` | 성공: `{redirectTo}` / 실패: `{error, remainingAttempts?, lockedUntil?}` |

**강화 내용**: 기존 validateUser에 실패 제한, 잠금 확인, 감사 로그 추가

#### Phase 2: 비밀번호 재설정

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| POST | `/api/forgot-password` | 재설정 요청 (이메일 발송) | 없음 | `{email}` | `{message: "이메일이 발송되었습니다"}` (항상 성공) |
| GET | `/api/reset-password/:token` | 토큰 유효성 검증 | 없음 | - | `{valid: true, email}` / `{valid: false, reason}` |
| POST | `/api/reset-password/:token` | 비밀번호 재설정 실행 | 없음 | `{password, confirmPassword}` | `{message: "비밀번호가 변경되었습니다"}` |

#### Phase 4: 비밀번호 강제 변경

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| POST | `/api/change-password` | 첫 로그인/만료 비밀번호 변경 | OIDC 세션 | `{password, confirmPassword}` | `{redirectTo}` |

### Main Server API (신규)

#### Phase 2: 비밀번호 변경

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| POST | `/api/v1/auth/change-password` | 비밀번호 변경 | JWT | `{currentPassword, newPassword, confirmPassword, logoutOtherDevices?}` | `{message}` |

#### Phase 1: 로그아웃 강화

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| POST | `/api/v1/auth/logout` | 로그아웃 **(강화)** | 쿠키 | - | `{message}` |

**강화 내용**: IDP Revocation + **End Session** + Access Token 블랙리스트 + Refresh Token 삭제

#### Phase 3: 세션 관리

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| GET | `/api/v1/auth/my-sessions` | 내 활성 세션 목록 | JWT | - | `{data: SessionInfo[]}` |
| POST | `/api/v1/auth/my-sessions/:grantId/revoke` | 특정 세션 종료 | JWT | - | `{message}` |
| POST | `/api/v1/auth/my-sessions/revoke-others` | 다른 모든 세션 종료 | JWT | - | `{message, revokedCount}` |

#### Phase 3: 관리자 보안 API (PLATFORM_ADMIN 전용)

| 메서드 | 경로 | 설명 | 인증 | 요청 | 응답 |
|--------|------|------|------|------|------|
| GET | `/api/v1/auth-audit-logs` | 감사 로그 목록 | JWT + PLATFORM_ADMIN | query: `{email?, result?, startDate?, endDate?, skip, take}` | `{data: AuditLog[], meta}` |
| POST | `/api/v1/users/:userId/unlock` | 계정 잠금 해제 | JWT + PLATFORM_ADMIN | - | `{message}` |
| POST | `/api/v1/users/:userId/force-reset-password` | 비밀번호 강제 재설정 | JWT + PLATFORM_ADMIN | - | `{message}` |
| POST | `/api/v1/users/:userId/invalidate-sessions` | 전체 세션 무효화 | JWT + PLATFORM_ADMIN | - | `{message, revokedCount}` |
| GET | `/api/v1/users/:userId/auth-audit-logs` | 특정 사용자 감사 로그 | JWT + PLATFORM_ADMIN | query: `{skip, take}` | `{data: AuditLog[], meta}` |

### API 응답 에러 코드

| HTTP | 에러 코드 | 설명 | 사용 위치 |
|------|----------|------|----------|
| 401 | `INVALID_CREDENTIALS` | 이메일/비밀번호 불일치 | 로그인 |
| 403 | `ACCOUNT_LOCKED_TEMPORARY` | 일시 잠금 (lockedUntil 포함) | 로그인 |
| 403 | `ACCOUNT_LOCKED_PERMANENT` | 영구 잠금 | 로그인 |
| 403 | `ACCOUNT_INACTIVE` | 비활성 계정 | 로그인 (응답은 INVALID_CREDENTIALS와 동일) |
| 400 | `PASSWORD_POLICY_VIOLATION` | 비밀번호 정책 미달 | 재설정, 변경 |
| 400 | `PASSWORD_REUSE` | 이전 비밀번호 재사용 | 재설정, 변경 |
| 400 | `TOKEN_EXPIRED` | 재설정 토큰 만료 | 재설정 |
| 400 | `TOKEN_ALREADY_USED` | 이미 사용된 토큰 | 재설정 |
| 400 | `CURRENT_PASSWORD_INCORRECT` | 현재 비밀번호 불일치 | 변경 |
| 403 | `MUST_CHANGE_PASSWORD` | 비밀번호 변경 필요 | 로그인 후 (Phase 4) |
