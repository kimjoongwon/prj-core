# L3-L4: 기능, 화면

## L3: Feature (기능)

### Phase 1: 로그인 강화 + 로그아웃 완성

| ID | 기능 | 위치 | 여정 | 설명 |
|----|------|------|------|------|
| AUTH-FEA-101 | 로그인 실패 제한 + 계정 잠금 | idp-server | 여정 2 | 연속 실패 5회→15분 잠금, 10회→영구 잠금, 자동 해제 |
| AUTH-FEA-102 | 감사 로그 저장 | idp-server | 여정 2 | 모든 로그인 시도를 AuthAuditLog에 기록 (성공/실패/잠금, IP, UA) |
| AUTH-FEA-103 | 로그인 UI 강화 | idp-client | 여정 2 | 남은 시도 횟수, 잠금 메시지, "비밀번호 찾기" 링크 |
| AUTH-FEA-104 | 로그아웃 완성 | main server | 여정 4 | OIDC 세션 종료 + Access Token 블랙리스트 + Refresh Token 삭제 |
| AUTH-FEA-105 | 세션 만료 UX | admin | 여정 3 | Refresh Token 갱신 실패 시 안내 메시지 + 로그인 페이지 이동 |

### Phase 2: 비밀번호 관리

| ID | 기능 | 위치 | 여정 | 설명 |
|----|------|------|------|------|
| AUTH-FEA-201 | 비밀번호 정책 유틸 | packages/be-common | 여정 5,6 | 8자+, 대/소문자, 숫자, 특수문자 검증 (프/백 공유) |
| AUTH-FEA-202 | 비밀번호 재설정 요청 | idp-server | 여정 5 | 이메일 → 재설정 토큰 생성 → Redis 저장(30분) → 이메일 발송 |
| AUTH-FEA-203 | 비밀번호 재설정 실행 | idp-server | 여정 5 | 토큰 검증 → 비밀번호 변경 → 전체 세션 무효화 |
| AUTH-FEA-204 | 비밀번호 찾기 UI | idp-client | 여정 5 | 이메일 입력 폼 → 발송 완료 메시지 |
| AUTH-FEA-205 | 비밀번호 재설정 UI | idp-client | 여정 5 | 토큰 검증 → 새 비밀번호 폼 (실시간 정책 검증) |
| AUTH-FEA-206 | 비밀번호 변경 API | main server | 여정 6 | 현재 비밀번호 확인 → 새 비밀번호 설정 → 이전 비밀번호 재사용 방지 |
| AUTH-FEA-207 | 비밀번호 변경 UI | admin | 여정 6 | 현재/새 비밀번호 폼 + 정책 검증 |
| AUTH-FEA-208 | 이메일 발송 서비스 | packages/be-service | 여정 5 | Nodemailer 기반 SMTP 이메일 발송 |
| AUTH-FEA-209 | 이전 비밀번호 재사용 방지 | idp-server/main server | 여정 5,6 | 최근 5개 비밀번호 해시 저장, 재사용 시 거부 |

### Phase 3: 세션 관리 + 관리자 도구

| ID | 기능 | 위치 | 여정 | 설명 |
|----|------|------|------|------|
| AUTH-FEA-301 | 내 세션 목록 API | main server | 여정 8 | Redis OIDC 세션에서 현재 사용자의 활성 세션 조회 |
| AUTH-FEA-302 | 다른 기기 세션 종료 | main server | 여정 8 | 특정 세션 또는 현재 세션 외 모든 세션 종료 |

| AUTH-FEA-304 | 감사 로그 조회 API | main server | 여정 9 | 필터링/페이지네이션 감사 로그 조회 (PLATFORM_ADMIN) |
| AUTH-FEA-305 | 감사 로그 Admin UI | admin | 여정 9 | DataGrid: 시간, 이메일, 결과, IP, UA |

| AUTH-FEA-307 | 비밀번호 강제 재설정 API | main server | 여정 9 | 임시 비밀번호 생성 → 이메일 발송 → 다음 로그인 시 변경 강제 |
| AUTH-FEA-308 | 사용자 전체 세션 무효화 API | main server | 여정 9 | 특정 사용자의 모든 OIDC Grant/세션 폐기 |
| AUTH-FEA-309 | 사용자 보안 탭 UI | admin | 여정 9 | 보안 정보 + 최근 로그인 + 관리 액션 버튼 |

### Phase 4: 비밀번호 라이프사이클

| ID | 기능 | 위치 | 여정 | 설명 |
|----|------|------|------|------|

| AUTH-FEA-404 | 만료 시 변경 강제 | admin | 여정 7 | 만료된 경우 비밀번호 변경 페이지로 강제 이동 |
