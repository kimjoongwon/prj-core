# AuthSecurity (인증 보안 강화)

> 레이어: _core / infrastructure
> 생성일: 2026-02-13

## 개요

실제 사용자가 경험하는 **인증 라이프사이클 전체**를 실무 제품 수준으로 강화합니다.
기능 나열이 아닌, 사용자 여정(사용자 여정) 중심으로 설계합니다.

### 현재 상태

| 시스템 | 포트 | 역할 |
|--------|------|------|
| core-api | :3006 | OIDC Provider (oidc-provider), 로그인/동의 API |
| main server | :3006 | OIDC Client, 비즈니스 API, 토큰 관리 |
| admin | :3000 | 관리자 웹 및 인증/동의 UI (Next.js) |

### 사용자 여정 기반 범위

```
[여정 1] 첫 접근 → 계정 생성(관리자) → 초대 이메일 → 첫 로그인 → 비밀번호 변경 강제
[여정 2] 일상 로그인 → 비밀번호 입력 → 실패 제한/잠금 → 성공 → Space 선택
[여정 3] 세션 유지 → Access Token 만료 → 자동 갱신 → Refresh Token 만료 → 재로그인
[여정 4] 로그아웃 → OIDC 세션 종료 → 쿠키/로컬스토리지 정리 → 로그인 페이지
[여정 5] 비밀번호 분실 → 이메일 재설정 → 새 비밀번호 → 전체 세션 무효화
[여정 6] 비밀번호 변경 → 현재 비밀번호 확인 → 정책 검증 → 이전 비밀번호 재사용 방지
[여정 7] 비밀번호 만료 → 로그인 시 변경 강제
[여정 8] 내 세션 관리 → 활성 세션 목록 → 다른 기기 종료
[여정 9] 관리자 보안 관리 → 잠금 해제/강제 재설정/세션 무효화/감사 로그
```
